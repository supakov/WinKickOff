# T05. Шаблоны XML и скриптов с маркерами

Статус: todo. Этап 2. Зависимости: T01. Может выполняться параллельно с T02-T04.

## Цель

Разделить `autounattend.xml` v0.2 на шаблон XML и три шаблона скриптов с маркерами `{{...}}` из
`02-architecture.md`, раздел 5, не меняя ни одного байта вне маркеров.

## Шаги

1. Скопировать `autounattend.xml` в `tests/golden/autounattend-v0.2.xml` (эталон, не редактировать).
2. `templates/autounattend.template.xml`: скелет XML, где вместо шапки-комментария, ключа, обходов,
   TimeZone, International-Core, OOBE, LocalAccounts и содержимого трёх `<File>` стоят маркеры.
   Отступы и переводы строк сохранить как в эталоне.
3. `templates/Setup-System.template.ps1`: текст скрипта с маркерами `{{config_block}}`,
   `{{apps_to_remove}}`, `{{asr_rules}}`, `{{geo_id}}`, `{{geo_name}}`.
4. `templates/Setup-User.template.ps1`: маркер `{{user_language_list}}` вместо трёх строк
   `New-WinUserLanguageList`/`Add`; запасной список тоже из маркера `{{user_language_fallback}}`.
5. `templates/Post-OOBE.template.ps1`: без маркеров (копия), но через тот же механизм.
6. `templates/VERSION` = `0.2`.
7. Документ `templates/README.md`: список маркеров, правило «любая правка шаблона требует новой
   версии и нового эталона».
8. Тест: подстановка значений v0.2 в шаблоны (временно вручную в тесте) даёт эталон побайтно.
   Этот тест станет golden-тестом в T06.

## Результат

Четыре шаблона, эталон, документ по маркерам; подстановка воспроизводит эталон.

## Критерии приёмки

- `diff` эталона и результата подстановки пуст (CRLF, без BOM, кодировка UTF-8).
- В шаблонах нет длинных тире, нет `]]>` внутри CDATA.
