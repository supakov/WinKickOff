# T10. Таблицы учётных записей, языков, ASR; списки приложений

Статус: todo. Этап 4. Зависимости: T09.

## Цель

Реализовать составные виджеты для типов `accounts`, `languages`, `apps`, `asr`.

## Шаги

1. `ui/accounts_table.py`: `Treeview` с колонками имя, отображаемое имя, группа, пароль (звёздочки
   или «нет»); кнопки Добавить, Изменить, Удалить, Вверх, Вниз; диалог редактирования с проверкой
   имени на лету (правила из валидатора); предупреждение при вводе пароля.
2. `ui/languages_table.py`: упорядоченный список тегов; добавление из `keyboards.json`; пометка
   «применяется при первом входе» для transient; первый в списке подсвечен как основной.
3. `ui/apps_list.py`: два списка: удаляемые с флажками (`Checkbutton` в прокручиваемом фрейме)
   с подписью и пояснением; сохраняемые как текст без флажков.
4. `ui/asr_table.py`: таблица правил с колонкой режима (`Combobox`: выключено, блокировать, аудит,
   предупреждать; «предупреждать» недоступно, если `supports_warn: false`) и колонкой риска.
5. Все составные виджеты пишут в профиль немедленно и ставят флаг изменений.
6. Тесты UI: добавление учётной записи через модель диалога, перестановка языков, снятие флажка
   приложения отражаются в профиле.

## Результат

Полный набор виджетов; пресет «Офис» открывается и отображается без потерь.

## Критерии приёмки

- Учётную запись с зарезервированным именем добавить нельзя (диалог показывает причину).
- Порядок языков после перестановки сохраняется в профиле и в XML.
