# T06. Генератор скриптов и XML из включённых правил

Статус: done (25.09.2026: `Renderer.build`, тесты `test_build.py`: детерминизм, выключенное правило
без следов, фазы без правил без скриптов, совпадение с v0.2, внешний `Validate-Unattend.ps1`). Этап 2.
Зависимости: T03, T04, T05. Веха M2. Отличие от шагов: маркер блока `# [id]` без названия правила,
потому что всё, что пишет генератор, только ASCII.

## Цель

Реализовать `core/render.py`: детерминированная сборка XML и трёх скриптов только из включённых правил.

## Шаги

1. `render_action(action, params) -> str` для каждого типа (`02-architecture.md`, раздел 6);
   экранирование строк PowerShell; подстановка `{param}` с приведением типа; `DU:` → `$du`.
2. `render_block(rule, state) -> str`: строка `# [id] title` плюс действия с отступом.
3. Сборка по фазам через `Resolver.apply_order`; инфраструктура фаз по наличию правил.
4. XML: команды windowsPE и specialize с `Order`; элементы OOBE; International-Core из профиля;
   учётные записи; ключ и `WillShowUI` по режиму; часовой пояс; шапка с версиями и именем профиля;
   встроенный профиль в `Extensions/Profile`.
5. `build(profile) -> BuildResult(xml, scripts, rule_ids, warnings)`; CRLF, без BOM.
6. `tests/test_render.py` по `04-testing.md`; сборка пресета «Офис» проходит `Validate-Unattend.ps1`
   (внешний тест).

## Критерии приёмки

- Выключенное правило отсутствует в выходе полностью.
- Все `Path` не длиннее 259; XML разбирается; профиль читается обратно.
- Два вызова дают одинаковые байты.
