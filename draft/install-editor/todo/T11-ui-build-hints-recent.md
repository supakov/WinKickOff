# T11. Подсказки, сборка из UI, экспорт, недавние файлы, настройки

Статус: todo. Этап 4. Зависимости: T07, T08, T10. Веха M3.

## Цель

Замкнуть цикл в интерфейсе: проверка, сборка, сохранение XML, подсказки по параметрам,
недавние профили, файл настроек приложения.

## Шаги

1. Кнопка «i» у параметра: всплывающее окно с `hint` и ссылкой «Подробнее», открывающей файл
   справочника через `os.startfile` (локальный путь из `doc`); если справочник не упакован,
   показывать только `hint`.
2. Меню Сборка: Проверить (валидатор профиля, результат в нижней панели с двойным щелчком к полю),
   Собрать XML (проверка → render → validate_xml → PowerShell-проверка в фоне → диалог сохранения,
   по умолчанию `output/autounattend.xml`), Открыть папку результата.
3. Меню Файл → Импорт из XML (T08).
4. Недавние файлы (до 8) в `settings.json` рядом с exe; профили с паролем помечены.
5. `settings.json`: язык интерфейса, геометрия окна, недавние; повреждённый файл игнорируется.
6. Диалог «О программе»: версия приложения, версия шаблона, ссылки на документацию.
7. Фоновая PowerShell-проверка через `threading.Thread` и `after()`; кнопки заблокированы на время.
8. Тесты UI: сборка из окна с пресетом «Офис» даёт golden; ошибка валидатора блокирует сборку.

## Результат

Пользователь проходит путь «новый → правка → сохранить → проверить → собрать → открыть папку» без консоли.

## Критерии приёмки

- Сборка из UI побайтно равна `render.build()` (UI ничего не добавляет).
- При ошибке валидатора файл не создаётся, сообщение указывает поле.
- Приложение не пишет ничего вне своей папки (тест: подмена `app_paths` на `tmp_path`, проверка файлов).
