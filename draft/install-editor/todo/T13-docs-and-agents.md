## Цель

Дать пользователю инструкцию, а агентам и разработчикам актуальную карту проекта.

## Шаги

1. `README-user.md` (кладётся в сборку): что это, как запустить с флешки, как создать профиль,
   собрать XML, положить на носитель, что проверить после установки (ссылка на корневой README

   SmartScreen на exe).

3. Обновить корневой `AGENTS.md`: структура `draft/install-editor/app/`, команды запуска, тестов,
   сборки; состояние задач T01-T13 «done»; правило golden-теста при правках шаблона.
4. Обновить `docs/02-constructor-requirements-draft.md`: пометить как исторический документ со
   ссылкой на `draft/install-editor/`.
5. Приёмочная установка в ВМ с файлом из сборки; результат в `docs/` как отчёт `04-acceptance-<дата>.md`.

## Результат

Документация пользователя в сборке; AGENTS.md актуален; приёмочный отчёт в `docs/`.

- Человек без знания проекта по README-user.md собирает XML за 10 минут.
