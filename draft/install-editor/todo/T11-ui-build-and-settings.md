# T11. Сборка из окна, проверка, экспорт, недавние, настройки

Статус: in-progress (25.09.2026: F7, F9 с проверкой PowerShell, диалог сохранения, папка результата,
меню Файл с пресетами, открытием, сохранением и импортом из XML, поле «Профиль» на панели; осталось:
недавние файлы, `settings.json`, фоновая проверка PowerShell, тест записи только в папку программы).
Этап 4. Зависимости: T07, T08, T10. Веха M4.

## Цель

Замкнуть цикл в окне: проверить, собрать, сохранить XML, импорт, недавние профили, `settings.json`.

## Шаги

1. Меню Сборка: Проверить (F7): результат в нижней панели, двойной щелчок ведёт к правилу или полю;
   Собрать (F9): проверка → сборка → проверка XML → PowerShell-проверка в фоне → диалог сохранения
   (по умолчанию `output/autounattend.xml`); Открыть папку.
2. Меню Файл: Новый из пресета, Открыть, Сохранить, Сохранить как, Импорт из XML, недавние (до 8).
3. `settings.json` рядом с exe: язык, геометрия, недавние; повреждённый файл игнорируется.
4. «О программе»: версии приложения и каталога, ссылки на документацию.
5. Фоновые операции через `threading.Thread` и `after()`; кнопки заблокированы на время.
6. Тесты: сборка из окна равна `Renderer.build`; ошибка валидатора блокирует сборку; приложение не
   пишет вне своей папки (подмена `app_paths` на временную папку).

## Критерии приёмки

- Полный цикл без консоли; ничего вне папки приложения.
