# T09. Главное окно и страницы групп

Статус: todo. Этап 4. Зависимости: T04.

## Цель

Построить главное окно по `02-architecture.md`, раздел 7: дерево групп, страницы с виджетами по
типам параметров, привязка к профилю, меню Файл.

## Шаги

1. `ui/main_window.py`: `PanedWindow` (дерево слева, Notebook справа), нижняя панель сообщений
   (пока пустая), строка состояния с именем профиля и признаком изменений.
2. `ui/widgets.py`: фабрика виджетов: bool → `Checkbutton`, int → `Spinbox` с проверкой диапазона,
   enum → `Combobox` только чтение, string → `Entry`; каждый виджет связан с `tk.Variable`, изменение
   пишет в профиль и ставит флаг изменений.
3. `ui/pages.py`: страница группы строится при первом выборе в дереве; сетка «подпись, виджет,
   кнопка i»; прокрутка через `Canvas`; кнопка «Сбросить группу».
4. Меню Файл: Новый (пресет «Офис»), Открыть, Сохранить, Сохранить как, Выход с вопросом при изменениях.
5. Отметка отклонения от умолчания: подпись жирным.
6. `depends` из схемы: виджет недоступен, если условие не выполнено (например `RemoveXboxServices`
   при выключенном `RemoveBloatApps` остаётся доступен, но `MapsBroker` пояснение меняется).
7. Тесты UI из `04-testing.md`, раздел 3 (создание окна, обход групп, привязка, сброс).

## Результат

Все параметры типов bool/int/enum/string редактируются через окно; профиль сохраняется.

## Критерии приёмки

- Обход всех групп не даёт исключений; каждый параметр схемы виден ровно один раз.
- Изменение флажка меняет профиль (тест) и заголовок окна (звёздочка).
