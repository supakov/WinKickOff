# T14. Локализация uk, сравнение профилей, пресет «Ноутбук»

Статус: todo. Этап 6 (дополнительно). Зависимости: T13.

## Цель

Украинский интерфейс, сравнение двух профилей в окне, пресет для ноутбуков.

## Шаги

1. `core/i18n.py`: загрузка `resources/strings.<lang>.json`, функция `t(key, **kw)`, язык из
   `settings.json`, переключение через меню с перезапуском окна.
2. Перевод всех строк интерфейса и `label.uk`/`hint.uk` в схеме и справочниках; тест полноты
   (каждый ключ есть в обоих языках, плейсхолдеры совпадают, длинных тире нет).
3. Диалог «Сравнить с профилем»: выбор файла, таблица `Profile.diff()` (параметр, значение A, значение B).
4. Пресет «Ноутбук»: `InactivityLockSeconds=600`, `PreventAutoDeviceEncryption=false` с обязательным
   предупреждением валидатора «сохраните ключ восстановления»; задел под будущую задачу BitLocker
   (отдельный скрипт вне этой версии).
5. Тесты: полнота переводов; diff двух пресетов содержит ожидаемые отличия.

## Результат

Интерфейс на двух языках, сравнение профилей, третий пресет.

## Критерии приёмки

- Переключение языка не требует пересборки.
- Тест полноты переводов зелёный.
