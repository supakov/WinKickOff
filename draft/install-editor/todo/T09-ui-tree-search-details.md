# T09. Дерево с флажками, поиск, панель описания

Статус: in-progress (25.09.2026: каркас окна с деревом, поиском и описанием создан). Этап 4.
Зависимости: T03, T04.

## Цель

Главное окно по `02-architecture.md`, раздел 8: дерево всех правил с флажками, поиск, описание с
технической таблицей действий, строка состояния каскада.

## Шаги

1. `ui/main_window.py`: `PanedWindow`, меню, строка состояния, горячие клавиши.
2. `ui/rule_tree.py`: построение из групп и правил; текст узла с символом состояния (☐ ☑ ◪);
   щелчок по символу или пробел переключает через резолвер; перерисовка изменённых узлов; флажок
   группы; сохранение состояния раскрытия.
3. Поиск: индекс из каталога; фильтрация с задержкой 150 мс; раскрытие совпадений; сброс.
4. `ui/detail_panel.py`: описание из данных правила и таблица действий, сгенерированная из `actions`;
   зависимости (требует, требуется для, конфликтует) как ссылки, переход по щелчку; «Подробнее»
   открывает файл справочника.
5. Строка состояния: «Выключено также: N», щелчок показывает список с причинами.
6. `tests/test_ui_smoke.py`: окно скрытое; дерево полное; поиск по ключу реестра; переключение
   меняет профиль.

## Критерии приёмки

- «Найти, выключить, собрать» в 4 действия (поле поиска, щелчок, F9, подтверждение пути).
- Каскад виден без диалога.
