# Редактор конфигурации установки (install-editor). Черновик проекта

Статус: постановка и план, 25.09.2026. Код не написан. Исполнение по задачам в `todo/`.

Что это: настольная программа для Windows, которая по форме с понятными переключателями собирает
`autounattend.xml` того же устройства, что `../../autounattend.xml` версии 0.2, хранит настройки в JSON
и проверяет результат до записи на носитель.

| [02-architecture.md](02-architecture.md) | Архитектура: модули, потоки данных, портабельность, структура каталогов, сборка |

Технологии, зафиксированные заказчиком: Python 3.14, tkinter (стандартная библиотека), только Windows,
портабельное приложение без установки и без привязки к путям системы; настройки и вспомогательные файлы
лежат рядом с исполняемым файлом.

Связанные документы проекта: справочник параметров `../../docs/reference/` (источник текстов подсказок
и правил валидации), черновик требований `../../docs/02-constructor-requirements-draft.md`
(предшественник этой постановки, сохранён для истории).
