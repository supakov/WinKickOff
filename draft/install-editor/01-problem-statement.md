# 01. Постановка задачи: редактор конфигурации установки Windows

Версия 0.1 от 25.09.2026. Основа: файл ответов v0.2 и справочник `docs/reference/`.

## 1. Цель

Дать администратору малой организации (или тому, кто им назначен) инструмент, который:

1. показывает все настройки установки Windows 11 Pro как форму с переключателями и пояснениями;
2. хранит выбранный набор как профиль в JSON (файл можно копировать, сравнивать, класть в архив);
3. собирает из профиля готовый `autounattend.xml`, идентичный по устройству проверенной версии 0.2;
4. проверяет результат по правилам, нарушение которых останавливает Windows Setup, до записи на носитель;
5. работает с флешки на любом ПК с Windows без установки и без прав администратора.

Итог: установка защищённой рабочей станции сводится к «выбрать профиль, нажать Собрать, скопировать
файл на флешку», а изменение политики организации к правке профиля, а не PowerShell-кода.

## 2. Пользователи и сценарии

| Роль | Кто это | Сценарий |
|---|---|---|
| Администратор организации | Сотрудник с базовыми навыками Windows, без опыта PowerShell | Открывает профиль «Офис», меняет имя администратора и часовой пояс, собирает XML, копирует на флешку |
| Технический специалист (аутсорс) | Обслуживает несколько организаций | Ведёт несколько профилей (бухгалтерия, ноутбуки, приёмная), сравнивает их, обновляет при выходе новой версии шаблона |
| Автор шаблона (этот проект) | Поддерживает скрипты и схему параметров | Добавляет параметр в схему и шаблон, тесты подтверждают, что старые профили собираются без изменений |

Сценарии использования:

1. Создать профиль с нуля из значений по умолчанию (совпадают с v0.2).
2. Открыть существующий профиль, изменить, сохранить под новым именем.
3. Собрать XML и сохранить в выбранную папку или прямо в корень флешки.
4. Проверить XML (кнопка) и увидеть список проблем с указанием, какое поле их вызвало.
5. Сравнить два профиля: список отличий по параметрам.
6. Прочитать подсказку по любому параметру: что делает, на что влияет, риски (тексты из справочника).
7. Импортировать `$Config` из уже существующего `autounattend.xml` v0.2 (обратный разбор блока), чтобы
   не терять ранее сделанные ручные правки.

## 3. Функциональные требования

### 3.1 Параметры

- Все параметры `$Config` версии 0.2, оба списка (`$AppsToRemove`, `$AsrRules`) и параметры XML
  (ключ и редакция, обход проверок, учётные записи, языки ввода, регион, язык интерфейса, часовой пояс).
- Каждый параметр описан в схеме (см. 03-data-model.md): идентификатор, группа, тип, значение по умолчанию,
  допустимые значения, подпись, краткое пояснение, ссылка на карточку в справочнике, признак «риск» и
  признак «только Enterprise/устаревшее».
- Список приложений: два списка в интерфейсе. «Удаляется» с флажками (можно снять), «Сохраняется всегда»
  без флажков (информационно). Каждое приложение с пояснением «что это и почему».
- Правила ASR: таблица с режимом на каждое правило (блокировать / аудит / предупреждать / выключено)
  и пояснением риска ложных срабатываний.
- Учётные записи: список из 1..N записей (имя, отображаемое имя, группа Administrators или Users,
  пароль необязателен). Хотя бы одна в Administrators. При заполненном пароле показывается предупреждение,
  что он попадёт в XML открытым текстом.
- Языки ввода: упорядоченный список из справочника раскладок (код языка, код раскладки, подпись);
  первый в списке становится основным. Языки без LCID (ru-UA) помечены как «применяется при первом входе».
- Профили-пресеты: «Офис» (= v0.2), «Строгий» (контролируемый доступ к папкам, SmartScreen Block,
  ASR prevalence в блокировку, NetBIOS выключен), «Ноутбук» (задел под BitLocker, отдельная задача).

### 3.2 Профиль JSON

- Один файл на профиль, UTF-8, читаемый человеком, ключи в порядке схемы.
- Содержит версию формата, версию шаблона, дату, комментарий автора и значения параметров.
- Отсутствующие параметры получают значения по умолчанию при загрузке (совместимость вперёд);
  неизвестные параметры сохраняются и показываются как предупреждение (совместимость назад).
- Профили лежат в `profiles/` рядом с исполняемым файлом; путь можно выбрать в диалоге.

### 3.3 Генерация XML

- Шаблон XML и три скрипта хранятся как файлы в `templates/` внутри приложения, не в коде.
- Генератор подставляет: блок `$Config`, `$AppsToRemove`, `$AsrRules`, учётные записи (для amd64 и arm64),
  International-Core, TimeZone, ключ и WillShowUI, набор команд LabConfig, комментарий шапки с версией.
- Golden-тест: профиль «Офис» со значениями по умолчанию обязан давать файл, побайтно равный
  эталону `tests/golden/autounattend-v0.2.xml` (копия проверенного файла). Это главный критерий,
  что генератор ничего не сломал.
- Результат пишется в UTF-8 без BOM, с переводами строк CRLF (как эталон).

### 3.4 Валидация

Встроенный валидатор повторяет `tools/Validate-Unattend.ps1` на Python и добавляет проверки на уровне профиля:

| Проверка | Уровень | Реакция |
|---|---|---|
| Длина каждого `Path` не более 259 символов | XML | Ошибка, сборка запрещена |
| Нет комментариев внутри `<component>` | XML | Ошибка |
| Все четыре значения International-Core заданы | XML | Ошибка |
| Формат InputLocale `LLLL:KKKKKKKK` | профиль | Ошибка |
| Имена учётных записей: уникальны, не зарезервированы, без запрещённых символов, до 20 символов | профиль | Ошибка |
| Хотя бы одна учётная запись в Administrators | профиль | Ошибка |
| Пароль задан | профиль | Предупреждение (открытый текст в XML) |
| `ControlledFolderAccess = 1` | профиль | Предупреждение (ломает старые программы) |
| `SmartScreenLevel = Block` | профиль | Предупреждение |
| `DisableNetBIOS = true` | профиль | Предупреждение (разрешение имён) |
| Параметр помечен «Enterprise only» и включён | профиль | Информация |
| `UILanguage` не совпадает с выбранным языком ISO | профиль | Предупреждение |
| Скрипты после подстановки проходят синтаксический разбор PowerShell 5.1 | XML | Ошибка (проверка через `powershell.exe` при наличии, иначе пропуск с пометкой) |

### 3.5 Интерфейс

- Главное окно: слева дерево групп (как разделы справочника), справа форма группы, внизу панель
  сообщений валидатора. Меню: Файл (новый, открыть, сохранить, сохранить как, недавние), Профиль
  (пресеты, сравнить), Сборка (проверить, собрать XML, открыть папку), Справка (о программе, справочник).
- Виджеты по типу параметра: флажок, поле, числовое поле со спином, выпадающий список, список
  с флажками, редактируемая таблица (учётные записи, языки).
- У каждого параметра значок «i» с всплывающим пояснением и ссылкой «подробнее» (открывает
  локальный файл справочника в браузере или встроенное окно с текстом).
- Индикация отклонения от умолчания (например, жирная подпись) и кнопка «Сбросить группу».
- Языки интерфейса программы: русский по умолчанию, украинский вторым; строки в отдельном файле.

## 4. Нефункциональные требования

| Требование | Значение |
|---|---|
| Платформа | Windows 10 1809+ и Windows 11, x64 |
| Язык и библиотеки | Python 3.14, tkinter/ttk из стандартной библиотеки; сторонние пакеты только для сборки (PyInstaller) и тестов (pytest) |
| Портабельность | Папка приложения копируется куда угодно; никаких записей в реестр, `%APPDATA%`, `%PROGRAMDATA%`; все пути вычисляются от папки исполняемого файла |
| Права | Работает без прав администратора; для записи в корень флешки достаточно прав пользователя |
| Запуск | Один exe (сборка onedir: exe плюс папка `_internal`), время старта до 2 секунд |
| Размер | До 40 МБ распакованных файлов |
| Автономность | Не обращается в интернет ни при каких действиях |
| Кодировки | UTF-8 везде; XML на выходе UTF-8 без BOM; профили UTF-8 |
| Логи | `logs/editor.log` рядом с exe, ротация по 1 МБ, три файла |
| Ошибки | Любая ошибка показывается пользователю понятным текстом и пишется в лог со стеком |
| Тесты | Модульные тесты на все модули без UI; golden-тест; дымовой тест UI; покрытие логики не ниже 80 % |
| Качество кода | `ruff` для стиля, аннотации типов, `mypy --strict` для модулей без tkinter |
| Стиль текстов | Без длинных тире в любых строках интерфейса, документации и комментариях |

## 5. Ограничения и допущения

- Целевая ОС для установки: Windows 11 Pro 24H2 и новее с официального ISO Microsoft. Шаблон
  скриптов версии 0.2 не переписывается редактором; редактор только заполняет параметры.
- Разметка диска в XML не задаётся (сознательное решение проекта): установщик спрашивает диск.
- Пароли в XML хранятся открытым текстом (ограничение формата Microsoft для `PlainText=true`;
  base64-вариант тоже обратим). Редактор предупреждает и не хранит пароли в недавних файлах.
- Редактор не запускает установку и не проверяет ISO; он производит только файл.
- Только Windows: используются пути с обратной косой чертой, `os.startfile`, диалоги tkinter.
- Вторичные языковые особенности (ru-UA без LCID) обрабатываются в скрипте первого входа, редактор
  их только показывает.

## 6. Критерии приёмки

1. Профиль «Офис» по умолчанию собирает XML, побайтно равный эталону v0.2.
2. Валидатор ловит каждую из ошибок раздела 3.4 на подготовленных плохих профилях (тесты).
3. Приложение запускается с флешки на чистой Windows 11 без Python и без прав администратора,
   создаёт `profiles/`, `logs/`, `output/` рядом с собой, не пишет в реестр и `%APPDATA%`.
4. Собранный из изменённого профиля файл проходит `tools/Validate-Unattend.ps1`.
5. Установка в виртуальной машине с собранным файлом проходит без вопросов, кроме выбора диска
   (ручной приёмочный тест на каждый выпуск).
6. Все тесты проходят на Python 3.14 в чистом виртуальном окружении.

## 7. Риски

| Риск | Вероятность | Смягчение |
|---|---|---|
| Новая версия Windows меняет поведение unattend (как удаление BypassNRO) | Средняя | Шаблон и скрипты версионируются отдельно от редактора; golden-тест на каждый шаблон |
| tkinter выглядит устаревшим и медленно рисует большие формы | Средняя | ttk-темы, ленивое построение вкладок, ограничение: до 60 виджетов на группу |
| PyInstaller-сборку блокирует Defender как неизвестный exe | Средняя | Подпись кода при наличии сертификата; иначе инструкция и добавление в исключения; SmartScreen Warn на целевых ПК позволяет запуск |
| Python 3.14 новый, PyInstaller может отставать | Средняя | Зафиксировать версию PyInstaller с поддержкой 3.14; запасной вариант: сборка на 3.13 без изменения кода |
| Рассинхронизация схемы параметров и скриптов | Высокая без контроля | Единый источник: схема; генератор и справочник читают её; тест, что каждый параметр `$Config` в шаблоне есть в схеме и наоборот |
| Пользователь редактирует XML вручную после сборки | Средняя | Импорт `$Config` обратно в профиль; валидатор как отдельная команда |
