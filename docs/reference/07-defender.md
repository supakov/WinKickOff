# 07. Microsoft Defender, правила сокращения поверхности атаки, SmartScreen

Раздел 3 `Setup-System.ps1`. Требование заказчика: штатный антивирус обязан работать. Файл ничего
в Defender не ослабляет, только включает дополнительные слои, которые на Pro по умолчанию выключены.

Все настройки записываются как политики в `Def` = `HKLM\SOFTWARE\Policies\Microsoft\Windows Defender`.
Это тот же путь, что использует групповая политика; Defender читает его напрямую, без запущенной
службы, поэтому метод надёжен в specialize. Побочный эффект: соответствующие переключатели в
«Безопасности Windows» становятся серыми с подписью «управляется администратором», что для
непрофессиональных пользователей желательно.

Защита от подделки (Tamper Protection) включена по умолчанию и не позволяет ослабить защиту через
реестр; включение дополнительных слоёв она не блокирует.

## Безусловные действия раздела

| Ключ | Действие | Смысл |
|---|---|---|
| `Def\DisableAntiSpyware`, `Def\DisableAntiVirus` | удаляются | Единственные значения, которыми сторонние скрипты отключают Defender |
| `Def\Real-Time Protection\DisableRealtimeMonitoring` | удаляется, затем = 0 | Защита в реальном времени включена |
| `Def\Real-Time Protection\DisableBehaviorMonitoring` | 0 | Поведенческий анализ включён |
| `Def\Real-Time Protection\DisableIOAVProtection` | 0 | Проверка скачанных файлов и вложений включена |
| `Def\Real-Time Protection\DisableScriptScanning` | 0 | Проверка скриптов (AMSI) включена |
| `Def\Windows Defender Exploit Guard\Controlled Folder Access\EnableControlledFolderAccess` | значение `ControlledFolderAccess` | См. ниже |
| `HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications\DisableNotifications` | 0 | Уведомления Безопасности Windows видны |
| `...\Notifications\DisableEnhancedNotifications` | 0 | Расширенные уведомления видны |
| `Pol\System\EnableSmartScreen` | 1 | SmartScreen для приложений и файлов включён |
| `Pol\System\ShellSmartScreenLevel` | значение `SmartScreenLevel` | См. ниже |

## DefenderCloudProtection

- Значение: `$true`.
- Что делает:
  - `Def\Spynet\SpynetReporting = 2`: участие в MAPS уровня «Расширенный» (облачная защита);
  - `Def\Spynet\SubmitSamplesConsent = 1`: автоматическая отправка безопасных образцов
    (без документов; файлы с личными данными не отправляются без запроса);
  - `Def\MpEngine\MpCloudBlockLevel = 2`: уровень облачной блокировки «Высокий»;
  - `Def\MpEngine\MpBafsExtendedTimeout = 50`: до 50 секунд дополнительного ожидания вердикта
    облака для подозрительного файла (по умолчанию 10).
- Ожидаемый эффект: новые вредоносные файлы, которых ещё нет в сигнатурах, блокируются по облачной
  репутации за секунды. Файл, который облако считает подозрительным, задерживается до минуты
  перед первым запуском.
- Кросс-связи:
  - Правила ASR «блокировать исполняемые файлы по распространённости», «защита от программ-вымогателей»
    и «обфусцированные скрипты» требуют включённой облачной защиты; без неё они не работают.
  - Уровень «Высокий» повышает долю ложных срабатываний на редких самописных программах
    (например внутренние утилиты бухгалтерии). Решение: исключения в Defender для конкретных файлов
    или снижение до 0 (по умолчанию).
  - Требуется интернет; в изолированной сети облачная защита просто не отвечает, локальные сигнатуры работают.
- Различия версий: значения доступны с Windows 10 1607 (уровень блокировки) и 1703 (тайм-аут).
  На Windows 11 24H2 без изменений. `MpCloudBlockLevel=4` («Высокий плюс») и 6 («Нулевая терпимость»)
  не выбраны из-за ложных срабатываний.
- Проверка: `Get-MpPreference | Select MAPSReporting, SubmitSamplesConsent, CloudBlockLevel, CloudExtendedTimeout`
  → 2, 1, 2, 50.
- Откат: удалить четыре значения; Defender вернётся к умолчаниям (MAPS расширенный, уровень 0).

## DefenderPUAProtection

- Значение: `$true`.
- Что делает: `Def\PUAProtection = 1`: блокировка потенциально нежелательных программ (adware,
  установщики-бандлы, майнеры, «оптимизаторы», торрент-клиенты с рекламой).
- Ожидаемый эффект: при скачивании или запуске такой программы Defender блокирует её и показывает
  уведомление. Для непрофессионалов это закрывает самый частый канал заражения: «бесплатная программа
  с сайта с кнопкой Скачать».
- Кросс-связи: дополняется `SmartScreenPuaEnabled` в Edge (раздел 10). Легитимные, но помеченные
  как PUA программы (например некоторые утилиты удалённого доступа) требуют исключения.
- Различия версий: политика с Windows 10 1607; в Параметрах переключатель появился в 2004.
  На 24H2 без изменений.
- Проверка: `Get-MpPreference | Select PUAProtection` → 1.
- Откат: удалить значение (умолчание на Pro: 0 выключено, но Edge SmartScreen PUA включён).

## DefenderNetworkProtection

- Значение: `$true`.
- Что делает: `Def\Windows Defender Exploit Guard\Network Protection\EnableNetworkProtection = 1`.
- Ожидаемый эффект: любое приложение (не только Edge) не может подключиться к доменам и адресам с
  плохой репутацией по данным SmartScreen: фишинг, командные серверы, эксплойт-киты. Пользователь
  видит уведомление «Подключение заблокировано».
- Кросс-связи:
  - Работает через драйвер фильтрации; на Windows 11 24H2 требует, чтобы Defender был основным
    антивирусом (при установке стороннего антивируса Defender переходит в пассивный режим и сетевая
    защита выключается).
  - Может конфликтовать с VPN-клиентами, использующими собственные фильтры; в таком случае режим
    аудита (2) даёт журнал без блокировки.
  - Не заменяет фильтрацию DNS; дополняет её.
- Различия версий: Windows 10 1709+. На Windows 11 24H2 работает также для QUIC/HTTP3 частично.
- Проверка: `Get-MpPreference | Select EnableNetworkProtection` → 1; тест
  `https://smartscreentestratings2.net` должен блокироваться.
- Откат: значение 0 или 2 (аудит).

## DefenderASRRules

- Значение: `$true`. Набор правил в `$AsrRules`.
- Что делает: `Def\Windows Defender Exploit Guard\ASR\ExploitGuard_ASR_Rules = 1` включает механизм;
  для каждого правила строковое значение `Def\...\ASR\Rules\<GUID>` = `1` (блокировать),
  `2` (аудит: только событие в журнале), `6` (предупреждать: пользователь может разрешить).
- Ожидаемый эффект: блокируются типовые техники заражения через Office, почту, скрипты и USB,
  которые Defender как антивирус по сигнатурам не ловит.
- Кросс-связи: ASR доступны на всех редакциях с Defender (включая Home), но управляются только через
  политики или PowerShell, в Параметрах их нет. События: журнал
  `Microsoft-Windows-Windows Defender/Operational`, ID 1121 (блок), 1122 (аудит), 1125/1126 (сетевая защита).
  Для правил Office требуется Office в `%ProgramFiles%` или `%ProgramFiles(x86)%`.
- Различия версий: минимальные сборки в таблице. На 24H2/25H2 все 17 правил поддерживаются.

## ControlledFolderAccess

- Значение: `0` (выключено). Допустимые: `1` блокировать, `2` аудит.
- Что делает: `Def\Windows Defender Exploit Guard\Controlled Folder Access\EnableControlledFolderAccess = <значение>`.
- Ожидаемый эффект при 1: запись в Документы, Изображения, Рабочий стол и другие защищённые папки
  разрешена только приложениям из списка доверенных Microsoft или добавленным вручную. Шифровальщик,
  запущенный пользователем, не сможет испортить документы.
- Почему выключено по умолчанию: программы учёта (1С, M.E.Doc, клиент-банки), старые версии Office
  и любые самописные программы, пишущие в Документы, будут заблокированы, а непрофессиональный
  пользователь не поймёт, что происходит. Включение требует ведения списка разрешённых приложений
  (`Add-MpPreference -ControlledFolderAccessAllowedApplications`). Рекомендуемый путь: режим аудита (2)
  на месяц, разбор событий 1123/1124, затем блокировка.
- Кросс-связи: правило ASR «защита от программ-вымогателей» частично покрывает ту же угрозу
  без списка приложений. Резервные копии остаются главной защитой от шифровальщиков.
- Различия версий: Windows 10 1709+. На 24H2 без изменений.
- Проверка: `Get-MpPreference | Select EnableControlledFolderAccess`.
- Откат: значение 0.

## SmartScreenLevel

- Значение: `'Warn'`. Допустимо `'Block'`.
- Что делает: `Pol\System\EnableSmartScreen = 1` и `Pol\System\ShellSmartScreenLevel = Warn|Block`.
- Ожидаемый эффект при Warn: запуск скачанного из интернета приложения без репутации показывает
  синее окно «Система Windows защитила ваш компьютер» с кнопкой «Выполнить в любом случае».
  При Block кнопки нет, запуск невозможен.
- Почему Warn: Block запретил бы установку любой малораспространённой программы (тех же программ
  учёта с сайтов разработчиков). Warn оставляет решение администратору, который знает, что ставит.
- Кросс-связи: работает по метке зоны интернета (Mark of the Web) на файле; файлы с флешек и из
  локальной сети метки не имеют и SmartScreen не проверяются (их покрывают правило ASR для USB и
  облачная защита). Edge имеет свой SmartScreen (раздел 10).
- Различия версий: политика `ShellSmartScreenLevel` с Windows 10 1703. На 24H2 без изменений.
- Проверка: Безопасность Windows → Управление приложениями и браузером → «Проверка приложений и файлов»
  показывает «Предупреждать» и «управляется администратором».
- Откат: удалить `ShellSmartScreenLevel` (останется умолчание Warn, но пользователь сможет выключить).
