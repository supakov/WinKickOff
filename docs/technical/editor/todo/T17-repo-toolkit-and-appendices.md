# T17. Repository root as a toolkit; XML into the documentation appendices

Status: done (25.09.2026). Stage 5. Dependencies: none.

## Goal

The repository root describes a new toolkit for installing and configuring Windows in workgroups,
the first tool of which is WinKickOff. The answer file of the original UnattendedWinstall and our last
hand-written v0.2 file move into the appendices section of the documentation as reference materials.

## Target structure (proposal)

```
Windows installer/                    WindowsInstaller repository
├── README.md                         toolkit: purpose, list of tools, quick start
├── AGENTS.md
├── WinKickOff/                       tool 1: editor and builder of autounattend.xml
├── tools/Validate-Unattend.ps1       auxiliary answer file verification tool
├── docs/
│   ├── README.md                     entry point to the documentation
│   ├── technical/ and user/          will appear in T16
│   └── appendices/
│       ├── README.md                 what the appendices contain and why
│       ├── A-unattendedwinstall/     autounattend.xml of the original, LICENSE, SOURCE.md (from original/)
│       ├── B-autounattend-v0.2/      our v0.2 file, README with version history v0.1-v0.2 and the VM checklist
│       ├── C-critical-review/        01-critical-review.md, 03-critic-report-v0.2.docx
│       └── D-winkickoff-office/      example: autounattend.xml built by WinKickOff from the «Офис» (Office) preset
└── docs/technical/editor/             specification (moves to docs/technical/editor/ in T16)
```

Appendix D is optional: an example of the program output for comparison with v0.2. If it is added, it should be
generated by a tool and checked by a test so that it does not fall behind the catalog.

## Steps

1. Move with `git mv` so that the file history is preserved.
2. Fix the paths according to the table; search the repository for remaining references (`autounattend.xml`, `original/`).
3. New root `README.md`: what the toolkit is, who it is for, the list of tools (WinKickOff, Validate-Unattend),
   where the documentation is, safety rules (a VM first).
4. `docs/appendices/README.md` and a README for each appendix.
5. Full run: `python -m unittest discover -s tests`, `Validate-Unattend.ps1` on Appendix B.
6. `AGENTS.md`, task index, commit and push.
