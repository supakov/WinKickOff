Статус: done (25.09.2026). Этап 5. Зависимости: нет.

## Цель

Корень репозитория описывает новый набор утилит для установки и настройки Windows в рабочих группах,
первая из которых WinKickOff. Файл ответов оригинала UnattendedWinstall и наш последний написанный
вручную файл v0.2 переезжают в раздел приложений документации как справочные материалы.

## Целевая структура (предложение)

```
Windows installer/                    репозиторий WindowsInstaller
├── README.md                         набор утилит: назначение, список утилит, быстрый старт
├── AGENTS.md
├── WinKickOff/                       утилита 1: редактор и сборщик autounattend.xml
├── tools/Validate-Unattend.ps1       вспомогательная утилита проверки файла ответов
├── docs/
│   ├── README.md                     точка входа в документацию
│   ├── technical/ и user/            появятся в T16
│   └── appendices/
│       ├── README.md                 что лежит в приложениях и зачем
│       ├── A-unattendedwinstall/     autounattend.xml оригинала, LICENSE, SOURCE.md (из original/)
│       ├── B-autounattend-v0.2/      наш файл v0.2, README с историей версий v0.1-v0.2 и чек-листом ВМ
│       ├── C-critical-review/        01-critical-review.md, 03-critic-report-v0.2.docx
│       └── D-winkickoff-office/      пример: autounattend.xml, собранный WinKickOff из пресета «Офис»
└── docs/technical/editor/             постановка (в T16 переезжает в docs/technical/editor/)
```

Приложение D необязательное: пример выхода программы для сравнения с v0.2. Если его добавлять, то
генерировать инструментом и проверять тестом, чтобы он не отставал от каталога.
