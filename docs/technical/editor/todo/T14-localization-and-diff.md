# T14. Локализация uk, сравнение профилей, пресет «Ноутбук»

Статус: todo. Этап 6 (дополнительно). Зависимости: T13.

## Цель

Украинский интерфейс и переводы правил, диалог сравнения профилей, третий пресет.

## Шаги

1. `core/i18n.py`: строки интерфейса из `resources/strings.<lang>.json`; переводы правил из
   `rules/lang/uk.toml` по ключу идентификатора; переключение через меню.
2. Перевод строк интерфейса и полей правил (`title`, `summary`, `effect`, `risk`, `versions`,
   `rollback`, названия параметров); тест полноты и отсутствия тире.
3. Диалог «Сравнить с профилем»: таблица `Profile.diff()`.
4. `profiles/preset-laptop.json`: блокировка через 10 минут, `PreventAutoDeviceEncryption`
   выключен с предупреждением валидатора о ключе восстановления.

## Критерии приёмки

- Переключение языка без пересборки; тест полноты переводов зелёный.
