# 05. Печать

Раздел 1 `Setup-System.ps1`. Требование заказчика: печать обязана работать сразу после установки.
Оригинальный файл UnattendedWinstall переводил диспетчер печати в ручной режим, из-за чего печать
не работала до ручного запуска службы.

## EnsurePrintSpooler

- Значение: `$true`.
- Где применяется: specialize, SYSTEM.
- Что делает:
  1. `HKLM\SYSTEM\CurrentControlSet\Services\Spooler\Start = 2` (Automatic) через реестр;
  2. `Set-Service -Name Spooler -StartupType Automatic` (дублирует через диспетчер служб, на случай
     если реестр перезапишется);
  3. `HKLM\SYSTEM\CurrentControlSet\Services\PrintNotify\Start = 3` (Manual, значение Windows по умолчанию).
- Ожидаемый эффект: служба «Диспетчер печати» запущена после каждой загрузки; принтеры USB и сетевые
  подключаются штатно; «Печать в PDF» и «XPS» доступны.
- Кросс-связи:
  - Диспетчер печати исторически главный источник уязвимостей удалённого выполнения кода
    (PrintNightmare 2021). Компенсация: `RestrictPrinterDriverInstallToAdmins` ниже и то, что входящие
    подключения по умолчанию заблокированы брандмауэром (раздел 09); общий доступ к принтеру
    открывает порт 445 только по правилу «Общий доступ к файлам и принтерам» в частном профиле.
  - Служба `PrintNotify` нужна для уведомлений о печати; ручной режим штатный.
- Различия версий: в Windows 11 22H2+ Microsoft переводит печать на IPP и «Windows Protected Print
  Mode» (WPP, 24H2): в этом режиме сторонние драйверы не используются, только универсальный класс-драйвер.
  WPP по умолчанию выключен; файл его не включает, потому что старые принтеры (Canon LBP, Samsung ML)
  требуют свои драйверы.
- Проверка: `Get-Service Spooler | Select Status, StartType` → Running, Automatic.
- Откат: `Set-Service Spooler -StartupType Manual`.

## RestrictPrinterDriverInstallToAdmins

- Значение: `$true`.
- Где применяется: specialize, политика в реестре.
- Что делает: ключ `HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Printers\PointAndPrint`:
  - `RestrictDriverInstallationToAdministrators = 1`: установка драйверов принтеров только администраторами;
  - `NoWarningNoElevationOnInstall = 0`: при подключении к принт-серверу показывать предупреждение
    и требовать повышение прав;
  - `UpdatePromptSettings = 0`: то же при обновлении драйвера.
- Ожидаемый эффект: стандартный пользователь User не сможет установить драйвер принтера. Подключение
  сетевого принтера с новым драйвером выполняет Admin. Подключение принтера, драйвер которого уже
  в системе (класс-драйверы, ранее установленные), работает для всех.
- Кросс-связи:
  - Это значение Windows по умолчанию с августа 2021 (KB5005652); файл фиксирует его политикой,
    чтобы никто не ослабил.
  - Для сетей с принт-сервером или общим принтером на другом ПК рабочей группы: при первом
    подключении User увидит запрос учётных данных администратора; с пустым паролем Admin запрос
    не пройдёт (раздел 03). Решение: Admin подключает принтер под своей учётной записью один раз
    для каждого пользователя, либо проект пользователей назначает пароли.
  - Будущий параметр конструктора: список доверенных принт-серверов
    (`PackagePointAndPrintServerList`), для которых установка разрешена всем.
- Различия версий: политика действует на Windows 10 1507+ и Windows 11 после KB5005652;
  на более старых сборках значение игнорируется.
- Проверка: `Get-ItemProperty 'HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\Printers\PointAndPrint'`.
- Откат: `RestrictDriverInstallationToAdministrators = 0` (не рекомендуется: возвращает вектор PrintNightmare).
