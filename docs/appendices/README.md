# Приложения

Справочные материалы, из которых вырос набор утилит. Они не меняются: новые файлы ответов собирает
WinKickOff, а изменения вносятся в его каталог правил.

| Приложение | Что внутри | Зачем |
|---|---|---|
| [A. UnattendedWinstall](A-unattendedwinstall/SOURCE.md) | Оригинальный `autounattend.xml` проекта UnattendedWinstall (memstechtips), лицензия MIT | Исходный материал критического разбора; в проекте не используется |
| [B. Файл ответов v0.2](B-autounattend-v0.2/README.md) | Наш последний файл ответов, написанный вручную (13.09.2026), история версий, чек-лист проверки в ВМ | Эталон: пресет «Офис» в WinKickOff повторяет его по всем действиям; валидатор проверяет его по умолчанию; тесты сравнивают сборки с ним |
| [C. Критический разбор](C-critical-review/01-critical-review.md) | Разбор оригинала и [отчёт независимого критика по v0.2](C-critical-review/03-critic-report-v0.2.docx) | Почему в проекте сделано так, а не как в оригинале |
| [D. Черновик требований](D-requirements-draft/02-constructor-requirements-draft.md) | Первый черновик требований к конструктору (12.09.2026), раздел 6: открытые вопросы заказчику | История постановки; вопросы раздела 6 ещё актуальны |

Файлы ответов лежат здесь в том виде, в каком были последний раз проверены. Файл приложения B
побайтно совпадает с тем, что лежал в корне репозитория до реорганизации 25.09.2026
(SHA-256 `2fbe72a693a4bd26411250209b576c921dbb2427622b782742c7300dc66572cc`).
