# Критический разбор autounattend.xml из UnattendedWinstall

Разбирается файл [`A-unattendedwinstall/autounattend.xml`](../A-unattendedwinstall/autounattend.xml) (3135 строк, 210 КБ, скачан 12.09.2026).
Из них 260 строк собственно XML и около 2900 строк PowerShell, встроенного в секцию `Extensions`.
Оценка ведётся с одной позиции: подходит ли это для рабочих групп без домена, где за ПК сидят
непрофессионалы, а специалистов по безопасности нет.

## 1. Общая картина

Файл сгенерирован программой Winhance и рассчитан на домашнего пользователя-энтузиаста:
максимальная очистка, отключение всего «лишнего», внешний вид под вкус автора.
Для рабочей группы это неверная цель. Три главные претензии:

1. Безопасность системно ослабляется (UAC, блокировка экрана, обслуживание, уведомления, обновления Store).
2. Удаляются компоненты, без которых система не обслуживается (Microsoft Store, Edge как единственный браузер).
3. Механизмы применения хрупкие и непрозрачные: задачи планировщика, которые крутятся при каждом входе,
   запуск процессов от имени пользователя через WinAPI, принудительная перезагрузка через 20 секунд после первого входа,
   ярлык на рабочем столе, который скачивает и запускает код из интернета (`irm ... | iex`).

Что в оригинале сделано хорошо и взято в новую версию: схема хранения скриптов внутри XML с извлечением
в проходе specialize, ключ BypassNRO для локальной учётной записи, включение .NET 3.5 с носителя,
показ расширений файлов, отключение рекламы и телеметрии, поддержка длинных путей.

## 2. Проход windowsPE (установщик)

| Что в оригинале | Проблема | В новой версии |
|---|---|---|
| Ключ `00000-00000-...`, `WillShowUI=Always` | Окно ввода ключа и выбора редакции показывается всегда | Универсальный ключ Pro, `WillShowUI=OnError`: ни ключа, ни выбора редакции |
| Обход TPM, Secure Boot, CPU, RAM, диска | Приемлемо для старого парка, на совместимом железе ничего не ослабляет | Оставлено, помечено как параметр |
| Компонент x86 | Windows 11 не бывает 32-битной, лишний объём | Убран, остались amd64 и arm64 |
| Нет языка установщика | Первый экран показывается | Оставлено намеренно, зависит от ISO |

## 3. Проход specialize

| Что в оригинале | Проблема | В новой версии |
|---|---|---|
| Отключение всех сетевых адаптеров на время OOBE | Если первый вход не случится или команда упадёт, ПК остаётся без сети. Нужно было только потому, что учётная запись создаётся руками в OOBE | Не нужно: учётные записи создаются из файла, OOBE не требует ни сети, ни аккаунта Microsoft |
| Один скрипт на 2900 строк | Смешаны настройки машины, пользователя, удаление приложений, косметика | Три коротких скрипта с чёткими ролями и блоком `$Config` |
| Часовой пояс не задан | Определяется по региону в OOBE, который тоже не задан | FLE Standard Time (Киев) |

## 4. Проход oobeSystem

| Что в оригинале | Проблема | В новой версии |
|---|---|---|
| Нет `UserAccounts` | Учётную запись создаёт человек руками, имена и группы не контролируются | Admin (Administrators) и User (Users) из файла |
| Нет `International-Core` | Языки ввода и регион остаются английскими или спрашиваются | EN, UK, RU для экрана входа и профиля по умолчанию, регион Украина |
| `NetworkLocation=Work` | Элемент устарел и игнорируется Windows 10/11 | Убран |
| `FirstLogonCommands` включают адаптеры | Зависит от первого входа | Не нужны |

## 5. Ослабление безопасности в оригинале

Это самый важный раздел. Каждая строка ниже в оригинале присутствует буквально.

| Настройка | Значение в оригинале | Последствие | В новой версии |
|---|---|---|---|
| `ConsentPromptBehaviorAdmin` | 0 | UAC не спрашивает администратора вообще: любая программа получает права без клика | 2 (спрашивать всегда, на защищённом рабочем столе) |
| `PromptOnSecureDesktop` | 0 | Окно UAC можно подменить или закликать программно | 1 |
| `DisableLockWorkstation` | 1 | Win+L и блокировка экрана запрещены | 0, плюс автоблокировка через 15 минут простоя |
| `MaintenanceDisabled` | 1 | Отключено автоматическое обслуживание, в том числе плановые проверки Defender | Не трогается |
| `ToastEnabled` (HKCU) | 0 | Отключены все уведомления, включая предупреждения безопасности | Не трогается |
| `AutoDownload` для Store | 2 | Приложения из Store не обновляются | Политика удалена |
| `AllowMUUpdateService` | 0 | Office и другие продукты Microsoft не получают обновления через Windows Update | 1 |
| `ExcludeWUDriversInQualityUpdate` | 1 | Драйверы с уязвимостями не обновляются | Политика удалена |
| `DODownloadMode` | 99 | Delivery Optimization полностью выключен | 1 (только внутри локальной сети) |
| Экран на питании от сети | никогда не гаснуть | Рабочее место остаётся открытым | Не трогается, действует автоблокировка |
| Удаление Microsoft Store | да | Нельзя обновлять и ставить приложения, ломаются зависимости других программ | Store сохранён |
| Удаление Microsoft Edge | да | Система без браузера; невозможно скачать другой браузер без стороннего носителя | Edge сохранён и ужесточён политиками SmartScreen |
| Перехват `ie_to_edge_stub.exe` через IFEO Debugger | да | Техника закрепления вредоносного ПО (MITRE T1546.012), антивирусы на неё реагируют | Убрано |
| Служба Spooler | Manual | Печать не работает, пока службу не запустят вручную | Automatic |
| Служба SysMain | Disabled | На HDD система заметно медленнее | Не трогается |
| Служба WSearch | Manual | Поиск в Outlook и проводнике перестаёт работать | Не трогается |
| Службы смарт-карт (SCardSvr и другие) | Manual | Токены ЭЦП запускают их по требованию, но лучше не трогать | Не трогаются |
| Ярлык «Install Winhance» | `irm get.winhance.net \| iex` | Приучает пользователя запускать код из интернета одним кликом | Убран |

## 6. Удаление приложений

Оригинал удаляет 44 пакета, среди них нужные в офисе: Store, Photos, Paint, Camera, Sound Recorder,
Sticky Notes, Notepad не трогает, но восстанавливает устаревший Windows Photo Viewer через правку HKCR.

Новая версия удаляет только то, что не нужно в рабочей группе и увеличивает поверхность атаки или
тянет данные в облако: Xbox, Bing-приложения, Solitaire, Get Help, Feedback Hub, 3D Viewer, Mixed Reality,
Maps, People, Phone Link, Power Automate, To Do, Family, Dev Home, Clipchamp, Teams (личный), Skype,
Office Hub, новый Outlook, Почта и Календарь, Copilot, Cortana, Quick Assist (используется мошенниками
«техподдержки»). Все имена сверены со списком пакетов Windows 11 25H2.

OneDrive не удаляется: без учётной записи Microsoft он не активен, а удаление скриптом с `takeown`
и отложенным удалением файлов при перезагрузке избыточно.

## 7. Механизмы применения

| Оригинал | Проблема | Новая версия |
|---|---|---|
| Три задачи планировщика (BloatRemoval при каждом входе, EdgeRemoval при каждой загрузке, OneDriveRemoval) | Постоянная фоновая активность, борьба с обновлениями Windows, которые возвращают компоненты | Удаление один раз в specialize; что вернётся с обновлением, вернётся осознанно |
| Задача WinhanceUserCustomizations от SYSTEM, поиск залогиненного пользователя, `CreateProcessAsUserW`, затем `shutdown /r /t 20` | Сложно, непрозрачно, перезагрузка без предупреждения через 20 секунд после первого входа | Active Setup: штатный механизм Windows, выполняется один раз при первом входе каждого пользователя |
| Настройки HKCU применяются к текущему пользователю | Второй пользователь их не получает | Настройки записаны в профиль по умолчанию, их наследуют все |
| Файл ответов остаётся в `C:\Windows\Panther` | На 24H2 там лежат имена учётных записей и пароли открытым текстом | Post-OOBE.ps1 удаляет копии после завершения OOBE |

## 8. Косметика, которой нет в новой версии

Тёмная тема, обои, классическое контекстное меню Windows 10, выравнивание панели задач влево, маленькие значки,
отключение анимаций, «End Task» в панели задач, чистое меню Пуск, план электропитания «Winhance Power Plan»
с отключением гибернации и быстрого запуска. Всё это дело вкуса пользователя, а не базового образа рабочей группы.
Если часть окажется нужной, она добавится как отдельный необязательный профиль конструктора.

## 9. Что добавлено сверх оригинала ради безопасности

Все пункты включаются и выключаются в `$Config`.

- Defender: облачная защита уровня High, автоматическая отправка безопасных образцов, защита от нежелательных программ,
  сетевая защита, 17 правил сокращения поверхности атаки (Office, почта, скрипты, USB, драйверы, шифровальщики).
- Защита учётных данных: LSA Protection, NTLMv2 only, отказ от WDigest, анонимный доступ запрещён, блокировка учётной записи после 10 неверных паролей.
- Сеть: SMBv1 выключен, подпись SMB обязательна, LLMNR выключен (защита от подмены имён в локальной сети), брандмауэр включён на всех профилях с журналом отброшенных пакетов.
- Съёмные носители и скрипты: автозапуск выключен для всех типов дисков, файлы `.js .vbs .hta` и подобные по двойному клику открываются в Блокноте.
- Журналирование для расследований: аудит создания процессов с командной строкой, входов и блокировок, журнал Security 256 МБ, журналирование PowerShell, отключён PowerShell 2.0.
- Удалённый доступ: удалённый помощник, входящий RDP и удалённый реестр выключены; если RDP включат, потребуется NLA.
- Автоматическое шифрование BitLocker запрещено: без домена ключ восстановления некуда сохранить, риск потери данных выше риска кражи. Включать осознанно с сохранением ключа.
