# WinKickOff: посібник користувача

WinKickOff збирає файл `autounattend.xml` для автоматичного встановлення Windows 11 Pro. Файл записують
на флешку з інсталяційним образом Windows; інсталятор сам знаходить його і налаштовує комп'ютер: захист,
оновлення, облікові записи, мови, видалення зайвих застосунків. Людині залишається вибрати диск.

Програма призначена для невеликих організацій без домену Windows, де немає окремого адміністратора
для кожного комп'ютера. Налаштування зібрано в готові набори (пресети), і їх можна змінювати без знання реєстру.

## Що знадобиться

- Комп'ютер із Windows 10 або 11, на якому запускають WinKickOff. Програмі не потрібні права
  адміністратора, вона нічого не змінює на цьому комп'ютері й записує файли лише у свою папку.
- Офіційний образ (ISO) Windows 11 із сайту Microsoft і флешка обсягом від 8 ГБ.
- Для першої перевірки: віртуальна машина (Hyper-V або VirtualBox). Новий файл спочатку перевіряють
  на ній і лише потім на робочих комп'ютерах.

## Як запустити програму

Якщо програму отримано у вигляді папки з файлом `WinKickOff.exe`, запустіть цей файл. Якщо отримано
вихідний код, потрібен Python 3.14 для Windows; у папці `WinKickOff` виконайте:

```powershell
python -m winkickoff
```

Мова інтерфейсу (українська, англійська або російська) обирається в меню «Мова»; програма запам'ятовує
вибір і зберігає відкритий профіль під час перемикання.

## Коротко

1. Виберіть профіль «Пресет: Офіс».
2. За потреби вимкніть або налаштуйте правила в дереві ліворуч.
3. Натисніть «Зібрати autounattend.xml» (F9) і збережіть файл.
4. Скопіюйте файл у кореневу папку флешки з образом Windows 11 і встановіть Windows на віртуальну машину.
5. Перевірте результат за списком із документа «Встановлення і перевірка», потім використовуйте файл на робочих комп'ютерах.
