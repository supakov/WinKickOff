# Безпека

## Спочатку віртуальна машина

З кожним новим або зміненим файлом відповідей Windows спочатку встановлюють на віртуальну машину.
Лише після перевірки за документом «Встановлення і перевірка» файл використовують на робочих
комп'ютерах. Встановлення стирає вибраний розділ диска: на комп'ютері з даними вибирайте розділ уважно.

## Стартові облікові записи без паролів

Admin (адміністратор) і User (звичайний користувач) створюються без паролів. Це свідоме рішення:
паролі та групи призначає окремий проєкт після встановлення. Доки паролі не призначено:

- User не може підтвердити запит контролю облікових записів, увівши дані Admin (Windows не приймає
  порожній пароль ніде, крім входу безпосередньо за комп'ютером); програми встановлюють під обліковим
  записом Admin;
- спільні папки між комп'ютерами не працюють: Windows не допускає підключення через мережу з порожнім паролем.

Пароль, заданий у програмі, записується у файл відповідей відкритим текстом. Такий файл і профіль
зберігайте в таємниці. Копії файлу відповідей видаляються з комп'ютера, на який встановлено систему,
через дві хвилини після початкового налаштування.

## Правила з ризиком

Правила рівня «ризиковане» виділено в дереві кольором, а перевірка (F7) попереджає про
кожне ввімкнене. Вимкнення правил рівня «базове» теж спричиняє попередження: вони становлять
основу захисту.

## Мова інтерфейсу і розкладки клавіатури

Мова інтерфейсу Windows береться з інсталяційного образу і не змінюється. Правило мов введення змінює
лише список розкладок клавіатури кожного користувача під час першого входу. Якщо після першого входу
розкладки не такі, як очікувалося, перегляньте журнал `Setup-User.<ім'я>.log` і виправте список
у «Параметрах» Windows (розділ мов); інших налаштувань системи це правило не торкається.

## Комп'ютер, на якому працює WinKickOff

Програма нічого не змінює на комп'ютері, на якому її запущено: не записує в реєстр, не встановлює
служби, не підключається до інтернету. Усі її файли (профілі, зібрані файли, журнал, налаштування)
зберігаються в її власній папці.
Сервер MCP (меню «MCP») за замовчуванням вимкнений; увімкнений, він приймає з'єднання лише з цього комп'ютера,
лише за токеном доступу і лише для читання, доки ви самі не зміните режим.
