# Профили и пресеты

Профиль хранит всё, что выбрано в программе: какие правила включены, значения параметров, редакцию и
ключ, часовой пояс, языки и учётные записи. Профиль это файл `.json` в папке `profiles` рядом с программой.

## Пресеты

| Пресет | Для чего |
|---|---|
| «Офис» | Обычные рабочие компьютеры. Основан на проверенном файле ответов v0.2: Defender с облачной защитой и правилами ASR, обновления Windows, печать, защита сети, журналы для расследования инцидентов, удаление рекламных и игровых приложений. Кроме того: политики браузеров Edge, Chrome и Brave без телеметрии, рекламы и ИИ-функций, OneDrive не устанавливается, диспетчер задач и другие средства Windows открываются у Admin без запроса UAC |
| «Строгий» | Компьютеры с повышенным риском. «Офис» плюс защита папок от шифровальщиков в режиме блокировки, запрет запуска программ без репутации (SmartScreen), блокировка редких исполняемых файлов, запрет неподписанных программ с флешек, запрос UAC у Admin при любом повышении прав, обновления других продуктов Microsoft (Office, .NET), выключенный NetBIOS, удалённый движок VBScript. Старые программы могут перестать работать: проверьте на одном компьютере |
| «Ноутбук» | Ноутбуки. «Офис», но экран блокируется через 10 минут бездействия. Диск не шифруется, как и в остальных пресетах: BitLocker включается отдельно, вместе с сохранением ключей восстановления и паролями пользователей |
| «memstechtips» | Сравнение и перенос привычных настроек. Повторяет оригинальный файл UnattendedWinstall (проект memstechtips, приложение A) настолько, насколько позволяет каталог: обход проверок оборудования, удаление приложений, отключение рекламы, Copilot и лишней телеметрии. Базовые правила защиты, которых нет в оригинале или которые ему противоречат (UAC, защита в реальном времени, NLA и другие), выключены, и программа предупреждает о каждом. Для рабочих компьютеров лучше «Офис». Подробный разбор на английском: [memstechtips-profile.md](../../technical/memstechtips-profile.md) |

Пресеты не меняются. Если изменить пресет и нажать «Сохранить», программа предложит сохранить профиль
под новым именем. Имена `preset-*.json` зарезервированы.

## Свои профили

- «Сохранить как...» создаёт новый профиль; его имя становится названием профиля.
- Поле «Профиль» на панели сверху переключает пресеты и сохранённые профили. Если текущий профиль
  изменён, программа спросит, сохранить ли изменения.
- «Файл, Недавние» открывает до восьми последних профилей и файлов.
- «Файл, Сравнить с профилем...» показывает, чем текущий профиль отличается от другого профиля или пресета:
  состояния правил, значения параметров, данные установки. Двойной щелчок по строке ведёт к правилу.

## Перенос на другой компьютер

Скопируйте файл профиля из папки `profiles` в такую же папку WinKickOff на другом компьютере. Если
в профиле заданы пароли, храните файл как секрет: пароли записаны открытым текстом.

## Восстановление из готового файла

«Файл, Открыть профиль из autounattend.xml» восстанавливает профиль:

- из файла, собранного WinKickOff: профиль встроен в сам файл и восстанавливается полностью;
- из написанного вручную файла v0.2 и файла без встроенного профиля: профиль восстанавливается по
  действиям файла. Правила, которые нельзя определить однозначно, остаются как в каталоге и
  перечисляются в списке внизу окна. После восстановления нажмите «Проверить» (F7).

Восстановленный профиль нужно сохранить, чтобы использовать его снова.

## Профили после обновления программы

Новая версия программы открывает профили, сохранённые старой:

- правила, которые есть в профиле, сохраняют свои состояния и параметры, даже если в новой версии
  изменилось их значение по умолчанию;
- новые правила каталога получают значения по умолчанию; программа сообщает одной строкой, сколько их и
  сколько из них включено;
- правила, которых больше нет в каталоге, не теряются: они хранятся в разделе `unknown` профиля и
  возвращаются, если правило появится снова;
- устаревшие поля переносятся (например, страна из версии каталога 0.2), о чём тоже есть сообщение.

Пресеты всегда соответствуют своей версии программы. Чтобы получить в своём профиле новые рекомендации,
откройте пресет и выберите «Файл, Сравнить с профилем...»: список покажет каждое различие.
