# WinKickOff: руководство пользователя

WinKickOff собирает файл `autounattend.xml` для автоматической установки Windows 11 Pro. Файл кладётся
на флешку с установочным образом Windows; установщик сам находит его и настраивает компьютер: защиту,
обновления, учётные записи, языки, удаление лишних приложений. Человеку остаётся выбрать диск.

Программа рассчитана на небольшие организации без домена Windows, где нет отдельного администратора
на каждый компьютер. Настройки собраны в готовые наборы (пресеты), и их можно менять без знания реестра.

## Что понадобится

- Компьютер с Windows 10 или 11, на котором запускается WinKickOff. Программе не нужны права
  администратора, она ничего не меняет в этом компьютере и пишет файлы только в свою папку.
- Официальный образ (ISO) Windows 11 с сайта Microsoft и флешка от 8 ГБ.
- Для первой проверки: виртуальная машина (Hyper-V или VirtualBox). Новый файл сначала проверяют
  на ней, и только потом на рабочих компьютерах.

## Как запустить программу

Если программа получена папкой с файлом `WinKickOff.exe`, запустите этот файл. Если получены исходные
тексты, нужен Python 3.14 для Windows: дважды щёлкните `Start-WinKickOff.cmd` в корне папки проекта или в папке
`WinKickOff` выполните:

```powershell
python -m winkickoff
```

## Язык и оформление

Основной язык программы английский; русский и украинский переводы лежат в отдельных файлах, и программа
сама находит все доступные языки. По умолчанию выбирается язык Windows, если для него есть перевод, иначе
английский. Язык меняется в меню «Язык», цветовая схема в меню «Тема»: «Как в Windows» (светлая или тёмная,
как настроено в Windows), «Светлая», «Тёмная», бежево-кофейная «Латте» и шуточная «Матрица». Программа запоминает выбор и сохраняет
открытый профиль при переключении.

Свой язык добавляется без изменения программы: файл `strings.<код>.json` в папке `resources` (например
`strings.pl.json` с полем `"_language": "Polski"`) и файл `<код>.toml` с переводом правил в папке `rules\lang`.
Образец: файлы русского перевода. Непереведённые строки показываются по-английски. Своя цветовая схема: файл
`resources\themes\<имя>.json` по образцу `dark.json`. В портабельной версии эти папки лежат внутри `_internal`.

## Коротко

1. Выберите профиль «Пресет: Офис».
2. При необходимости выключите или настройте правила в дереве слева.
3. Нажмите «Собрать autounattend.xml» (F9) и сохраните файл.
4. Скопируйте файл в корень флешки с образом Windows 11 и установите Windows на виртуальную машину.
5. Проверьте результат по списку из документа «Установка и проверка», затем используйте файл на рабочих компьютерах.
