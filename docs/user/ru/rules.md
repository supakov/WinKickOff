# Список правил

Все правила каталога WinKickOff 0.8 по группам, всего 278. Файл создаётся из каталога командой `python tools/make_rule_docs.py`, вручную его не редактируют. В программе у каждого правила есть также технические детали, проверка после установки и откат.

Уровни: базовое (основа защиты, выключать не рекомендуется), рекомендуемое, необязательное, рискованное (может мешать программам, включать осознанно).

## Установка (windowsPE и specialize)

Обход проверок совместимости, локальная учётная запись без сети, .NET Framework 3.5 с носителя.

- **Обход проверки TPM 2.0** (`install.bypass-tpm`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Установщик не требует TPM 2.0. На ПК с TPM модуль остаётся включённым и используется.
  Эффект: Установка проходит на ПК без TPM или с TPM 1.2 без сообщения о несовместимости.
  Риск: Без TPM недоступны автоматическое шифрование устройства и BitLocker без пароля при загрузке. Microsoft не гарантирует обновления неподдерживаемым ПК.
- **Обход проверки Secure Boot** (`install.bypass-secureboot`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Установщик не требует включённой Secure Boot.
  Эффект: Установка проходит на ПК с BIOS/CSM или с выключенной Secure Boot.
  Риск: Без Secure Boot не работают Credential Guard и часть защит ядра; защита LSA в этом файле выбрана без привязки к UEFI именно ради таких ПК.
- **Обход проверки процессора** (`install.bypass-cpu`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Установщик не сверяет процессор со списком поддерживаемых.
  Эффект: Установка проходит на процессорах старше 8-го поколения Intel и Ryzen 2000.
  Риск: В 24H2 требование инструкций POPCNT и SSE4.2 не обходится: на очень старых процессорах установка невозможна.
- **Обход проверки объёма памяти** (`install.bypass-ram`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Установщик не требует 4 ГБ памяти.
  Эффект: Установка проходит на ПК с меньшим объёмом памяти; работа будет медленной.
- **Обход проверки размера диска** (`install.bypass-storage`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Установщик не требует 64 ГБ на диске.
  Эффект: Установка проходит на маленькие диски; место под обновления нужно контролировать.
- **Разрешить завершение OOBE без интернета и учётной записи Microsoft** (`install.bypass-nro`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Ключ BypassNRO: первичная настройка не требует подключения к сети и аккаунта Microsoft.
  Эффект: Страховка: учётные записи создаются из файла, но при изменении поведения OOBE ключ не даст установке застрять на экране сети. Нужен, когда учётная запись спрашивается при установке: без него OOBE может остановиться на экране сети.
- **.NET Framework 3.5 с установочного носителя** (`install.netfx3`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Ищет папку sources\sxs на подключённых дисках и включает .NET Framework 3.5 (включая 2.0 и 3.0) без интернета.
  Эффект: Старые программы учёта и банковские программы, а также драйверы ключей ЭЦП работают сразу после установки.
  Риск: Носитель должен оставаться подключённым во время первой перезагрузки; иначе компонент не установится и в лог попадёт WARN. Позже его можно добавить через Параметры при наличии интернета.

## Первичная настройка (OOBE)

Какие экраны первичной настройки скрываются и как задаются параметры конфиденциальности.

- **Скрыть экран лицензионного соглашения** (`oobe.hide-eula`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Лицензия принята в установщике (AcceptEula), экран в OOBE не показывается.
  Эффект: Одним экраном меньше; ответственность за принятие условий несёт организация.
- **Скрыть экран регистрации у производителя** (`oobe.hide-oem-registration`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Экран регистрации OEM не показывается (появляется только на образах производителей).
  Эффект: Безвредно на образах Microsoft; экономит экран на OEM-образах.
- **Скрыть экраны учётной записи Microsoft** (`oobe.hide-online-account`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Экраны входа в аккаунт Microsoft не показываются (Windows показывает их только при подключении к интернету). Экран локальной учётной записи пропускается, потому что учётные записи заданы в файле.
  Эффект: После подготовки система сразу показывает экран входа со стартовыми учётными записями. С режимом «Спросить учётную запись при установке» в форме «Учётные записи» Windows показывает только свой экран локальной учётной записи.
  Риск: Без правила Windows 11 Pro при подключении к интернету требует аккаунт Microsoft, в том числе когда учётная запись спрашивается при установке.
- **Скрыть экран подключения к сети** (`oobe.hide-wireless`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Экран «Подключитесь к сети» скрыт всегда, а не только при проводном подключении.
  Эффект: Установка не останавливается на ноутбуках без кабеля; Wi-Fi настраивается после входа.
- **Экран параметров конфиденциальности: отключить экспресс-параметры** (`oobe.protect-your-pc`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Экран конфиденциальности не показывается; отправка данных, реклама и определение местоположения по умолчанию выключены.
  Эффект: SmartScreen и Defender не затрагиваются: они включаются отдельными правилами.

## Печать

Диспетчер печати и защита установки драйверов принтеров.

- **Диспетчер печати запускается автоматически** (`printing.spooler-automatic`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Служба Spooler переводится в автоматический запуск (реестр и Set-Service), PrintNotify остаётся ручной.
  Эффект: Печать работает сразу после установки: принтеры USB и сетевые, «Печать в PDF». Служба запускается вместе с Windows, даже если раньше была переведена в ручной режим.
  Риск: Диспетчер печати исторически источник уязвимостей (PrintNightmare); компенсируется правилом установки драйверов только администраторами и брандмауэром.
- **Драйверы принтеров устанавливают только администраторы** (`printing.point-and-print-admins`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Политика Point and Print: установка и обновление драйверов принтеров требуют прав администратора и показывают предупреждение.
  Эффект: Стандартный пользователь не установит драйвер принтера; уже установленные драйверы и класс-драйверы доступны всем.
  Риск: Подключение сетевого принтера с новым драйвером выполняет администратор. Пока у Admin пустой пароль, запрос учётных данных у пользователя не пройдёт.

## Обновления Windows

Автоматические обновления, другие продукты Microsoft, отсрочка обновлений функций, Delivery Optimization.

- **Снять любые блокировки Центра обновления** (`update.unblock`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Удаляет политики, которые отключают обновления, драйверы или автообновление Store, и возвращает отключённые службы обновления в ручной режим.
  Эффект: На чистом образе ничего не меняет; защищает от следов сторонних «оптимизаторов» и делает повторный запуск скрипта безопасным.
- **Автоматическая установка обновлений и период активности** (`update.automatic`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Обновления скачиваются и ставятся сами; автоматическая перезагрузка запрещена в период активности.
  Эффект: Перезагрузка ночью или до начала рабочего дня; пользователь видит уведомление и может отложить в пределах политики.
  Риск: Период активности не длиннее 18 часов. ПК, работающие круглосуточно, перезагрузятся вне периода.
- **Обновления других продуктов Microsoft (Office, .NET)** (`update.other-microsoft-products`). Уровень: рекомендуемое. «Офис»: выключено; «Строгий»: включено.
  Подключение к Microsoft Update: исправления Office (MSI), .NET и других продуктов приходят вместе с Windows.
  Эффект: Переключатель в Параметрах включён и заблокирован. Office 365 (Click-to-Run) обновляется своим механизмом независимо.
- **Отсрочка обновлений функций** (`update.defer-feature`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Ежегодные обновления версии приходят с задержкой; ежемесячные обновления безопасности не откладываются.
  Эффект: За время отсрочки Microsoft исправляет ошибки первых недель, а программы учёта выпускают совместимые версии.
  Риск: Требует работающей оценки совместимости: правило минимальной телеметрии намеренно оставляет DiagTrack в ручном режиме, а не отключает.
- **Delivery Optimization: обмен обновлениями только в локальной сети** (`update.delivery-optimization-lan`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  ПК одной сети обмениваются скачанными фрагментами обновлений между собой; наружу ничего не отдаётся.
  Эффект: В офисе с десятком ПК обновление скачивается из интернета один раз. Нужен открытый порт 7680 между ПК (правило брандмауэра Windows создаёт сама).

## Microsoft Defender и SmartScreen

Защита в реальном времени, облачная защита, PUA, сетевая защита, правила ASR, SmartScreen.

- **Защита в реальном времени включена и закреплена** (`defender.realtime`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Удаляет значения, которыми сторонние скрипты отключают Defender, и закрепляет защиту в реальном времени, поведенческий анализ, проверку загрузок и скриптов.
  Эффект: Антивирус нельзя выключить через реестр; переключатели в Безопасности Windows управляются политикой.
- **Облачная защита: MAPS, отправка образцов, уровень блокировки** (`defender.cloud`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Участие в MAPS уровня «Расширенный», автоматическая отправка безопасных образцов, уровень облачной блокировки «Высокий», ожидание вердикта до 50 секунд.
  Эффект: Новые вредоносные файлы без сигнатур блокируются по облачной репутации за секунды; подозрительный файл задерживается до минуты перед первым запуском.
  Риск: Уровень «Высокий» повышает долю ложных срабатываний на редких самописных программах; решение: исключение для файла или уровень 0. Требует интернета.
- **Блокировать потенциально нежелательные программы (PUA)** (`defender.pua`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Defender блокирует adware, установщики-бандлы, майнеры и «оптимизаторы» при скачивании и запуске.
  Эффект: Закрывает самый частый канал заражения непрофессионалов: «бесплатная программа с сайта с кнопкой Скачать».
  Риск: Легитимные утилиты, помеченные как PUA (некоторые средства удалённого доступа), требуют исключения.
- **Сетевая защита: блокировать подключения к опасным адресам** (`defender.network-protection`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Любое приложение, не только Edge, не может подключиться к доменам с плохой репутацией по данным SmartScreen.
  Эффект: Фишинговые сайты и командные серверы блокируются с уведомлением «Подключение заблокировано».
  Риск: Работает только когда Defender основной антивирус; может конфликтовать с VPN-клиентами с собственными фильтрами (тогда режим аудита).
- **Механизм правил сокращения поверхности атаки (ASR) включён** (`defender.asr`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Включает механизм ASR; сами правила перечислены в подгруппе и настраиваются по одному.
  Эффект: Без этого правила ни одно правило ASR не действует.
- **Контролируемый доступ к папкам (режим)** (`defender.controlled-folder-access`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Записывает режим защиты папок Документы, Изображения, Рабочий стол. По умолчанию 0 (выключено) как политика: пользователь не включит случайно.
  Эффект: В режиме блокировки писать в защищённые папки могут только доверенные приложения; шифровальщик, запущенный пользователем, документы не испортит.
  Риск: Режим 1 ломает программы учёта и банковские программы, старый Office и любые самописные программы, пишущие в Документы. Рекомендуемый путь: месяц аудита (2), разбор событий 1123/1124, затем блокировка.
- **Уведомления Безопасности Windows видны** (`defender.notifications`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Политики уведомлений Центра безопасности закреплены во включённом состоянии.
  Эффект: Пользователь видит сообщения об угрозах и результатах проверок; ни одно уведомление Defender не отключается.
- **SmartScreen для скачанных программ и файлов** (`defender.smartscreen-shell`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Запуск скачанной из интернета программы без репутации показывает предупреждение (Warn) или запрещается (Block).
  Эффект: Работает по метке зоны интернета; файлы с флешек и из локальной сети не проверяются (их покрывают правило ASR для USB и облачная защита).
  Риск: Режим Block запрещает установку любой малораспространённой программы, включая программы учёта с сайтов разработчиков.

### Правила сокращения поверхности атаки (ASR)

Каждое правило блокирует одну технику атаки через Office, почту, скрипты, USB или драйверы. Режим: блокировать, аудит, предупреждать.

- **ASR: блокировать злоупотребление уязвимыми подписанными драйверами** (`asr.vulnerable-drivers`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Запрещает записывать на диск драйверы из списка Microsoft уязвимых (техника BYOVD для отключения антивируса).
  Эффект: Уже установленные драйверы не затрагиваются.
  Риск: Низкий: старые утилиты RGB-подсветки и разгона.
- **ASR: блокировать закрепление через подписки WMI** (`asr.wmi-persistence`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Безфайловое вредоносное ПО не может закрепиться в репозитории WMI.
  Эффект: Закрывает технику скрытого автозапуска.
  Риск: Низкий; мешает клиенту SCCM, которого в рабочей группе нет.
- **ASR: Adobe Reader не запускает дочерние процессы** (`asr.adobe-reader-child`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Эксплойт в PDF не сможет запустить ничего из Adobe Reader.
  Эффект: Открытие PDF работает как прежде.
  Риск: Низкий.
- **ASR: приложения Office не запускают дочерние процессы** (`asr.office-child`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Макрос в Word или Excel не сможет запустить cmd, PowerShell или установщик.
  Эффект: Действует только если Office установлен в Program Files.
  Риск: Средний: надстройки, запускающие внешние программы.
- **ASR: блокировать исполняемое содержимое из почты и веб-почты** (`asr.email-executable`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Файлы .exe, .js, .zip, сохранённые из Outlook и веб-почты, не запускаются.
  Эффект: Закрывает вложения-загрузчики.
  Риск: Низкий.
- **ASR: блокировать запуск обфусцированных скриптов** (`asr.obfuscated-scripts`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  PowerShell, JS и VBS с признаками обфускации не выполняются. Требует облачной защиты.
  Эффект: Останавливает загрузчики, которые прячут код от антивируса.
  Риск: Средний: установщики некоторых программ используют обфускацию.
- **ASR: JavaScript и VBScript не запускают скачанное** (`asr.script-download`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Скрипт-загрузчик не сможет запустить только что скачанный файл.
  Эффект: Типовая схема «архив со скриптом внутри» перестаёт работать.
  Риск: Низкий.
- **ASR: Office не создаёт исполняемые файлы** (`asr.office-executable`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Макросы не могут записать на диск .exe, .dll или .vbs.
  Эффект: Закрывает закрепление через документы.
  Риск: Низкий.
- **ASR: Office не внедряет код в другие процессы** (`asr.office-injection`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Word, Excel, PowerPoint и OneNote не могут внедрять код в чужие процессы.
  Эффект: Легитимных причин для такой инъекции нет.
  Риск: Низкий; несовместимо с BeyondTrust Privilege Guard и Heimdal. Режим предупреждения не поддерживается.
- **ASR: Outlook не запускает дочерние процессы** (`asr.office-comm-child`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Защищает от эксплойтов правил и форм Outlook при украденных учётных данных.
  Эффект: Обычные функции Outlook работают.
  Риск: Низкий.
- **ASR: блокировать недоверенные и неподписанные программы с USB** (`asr.usb-untrusted`). Уровень: рекомендуемое. «Офис»: выключено; «Строгий»: включено.
  Неподписанные .exe, .dll и .scr не запускаются прямо с флешек и SD-карт.
  Эффект: Копирование файлов с флешки не блокируется, только запуск.
  Риск: Средний: портативные утилиты без подписи.
- **ASR: блокировать вызовы Win32 API из макросов Office** (`asr.office-win32-api`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  VBA-макросы не могут вызывать Win32 API (шелл-код без записи на диск).
  Эффект: Обычным макросам такие вызовы не нужны.
  Риск: Низкий.
- **ASR: расширенная защита от программ-вымогателей** (`asr.ransomware`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Файлы, похожие на шифровальщики по облачной эвристике и без положительной репутации, блокируются. Требует облачной защиты.
  Эффект: Дополнительный слой к сигнатурам и поведенческому анализу.
  Риск: Средний: редкие самописные программы блокируются, пока не наберут репутацию.
- **ASR: блокировать перезагрузку в безопасный режим из программ** (`asr.safe-mode-reboot`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Вредоносный код не может перевести ПК в безопасный режим, где антивирус не работает.
  Эффект: Безопасный режим по-прежнему доступен из среды восстановления.
  Риск: Низкий.
- **ASR: предупреждать о скопированных или поддельных системных утилитах** (`asr.copied-system-tools`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Копии утилит из system32, запущенные из других папок, блокируются с возможностью разрешить.
  Эффект: По умолчанию режим предупреждения: правило эвристическое.
  Риск: Повышенный: легитимные программы с именами системных утилит из нестандартных путей.
- **ASR: исполняемые файлы без репутации (аудит)** (`asr.prevalence`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Запуск редких или новых .exe журналируется (аудит). В режиме блокировки закрыл бы внутренние программы организации.
  Эффект: События 1122 в журнале Defender показывают, что было бы заблокировано.
  Риск: Высокий в режиме блокировки: собственные программы без репутации. Включать в строгом профиле после месяца аудита.
- **ASR: процессы из PsExec и WMI (аудит)** (`asr.psexec-wmi`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Удалённый запуск через PsExec и WMI журналируется. В режиме блокировки помешал бы удалённому администрированию своим специалистом.
  Эффект: Аудит показывает попытки горизонтального перемещения по сети.
  Риск: Высокий в режиме блокировки для администрирования через PsExec/WMI.
- **ASR: блокировать кражу учётных данных из LSASS** (`asr.lsass`). Уровень: необязательное. «Офис»: выключено; «Строгий»: выключено.
  Дублирует правило защиты LSA (RunAsPPL) и создаёт много шума в журнале; по умолчанию выключено.
  Эффект: Имеет смысл только там, где защиту LSA включить нельзя (неподписанные плагины смарт-карт).
  Риск: Много событий от легитимных программ (обновление Chrome и другие). Режим предупреждения не поддерживается.

## Безопасность

UAC, учётные записи, защита учётных данных, удалённый доступ, шифрование.

### Контроль учётных записей (UAC)

- **UAC включён, запросы на защищённом рабочем столе, Win+L работает** (`uac.baseline`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Базовые значения UAC: включён, запрос на защищённом рабочем столе, стандартный пользователь вводит учётные данные администратора, установщики требуют повышения, встроенный Administrator в режиме одобрения, сетевой вход локальных администраторов с фильтрованным токеном. Запрет блокировки экрана удалён.
  Эффект: UAC остаётся включённым: запросы на повышение прав появляются на защищённом рабочем столе, стандартный пользователь вводит учётные данные администратора, а Win+L блокирует экран.
- **UAC для администраторов: уведомлять всегда** (`uac.admin-always-notify`). Уровень: рекомендуемое. «Офис»: выключено; «Строгий»: включено.
  Администратор видит запрос при любом повышении, включая системные компоненты; закрывает известные обходы UAC через доверенные программы Windows.
  Эффект: Больше запросов «Да/Нет» у Admin, в том числе при открытии диспетчера задач (Ctrl+Shift+Esc), редактора реестра и других средств Windows, которые иначе повышаются без запроса; защита от автоматического повышения вредоносным кодом. У обычного пользователя (User) эти средства открываются без запроса в любом случае.
  Риск: С пустым паролем запрос UAC это только кнопка «Да»: защита от программ, а не от человека за клавиатурой.

### Учётные записи и вход

- **Блокировка экрана после простоя** (`accounts.inactivity-lock`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Через заданное число секунд без ввода экран блокируется независимо от заставки и питания.
  Эффект: Рабочее место не остаётся открытым; с пустым паролем разблокировка это Enter, смысл появится после назначения паролей.
- **Блокировка учётной записи после неверных паролей** (`accounts.lockout`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  После заданного числа неверных паролей подряд учётная запись блокируется на заданное время.
  Эффект: Перебор паролей по сети (SMB, RDP) бесполезен. С пустыми паролями неактуально; после назначения паролей первая линия защиты.
- **Срок действия паролей не ограничен (стартовые учётные записи)** (`accounts.password-never-expires`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Максимальный срок действия пароля снимается для всех локальных учётных записей (по умолчанию 42 дня).
  Эффект: Windows никогда не покажет «Ваш пароль истёк» для стартовых учётных записей с пустым паролем. Проект управления пользователями может вернуть срок действия при назначении паролей.
- **Без запроса «Разрешить организации управлять устройством»** (`accounts.block-aad-join`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  При входе в Office или Teams с рабочей учётной записью Windows не предлагает присоединить устройство к Entra ID.
  Эффект: Непрофессиональный пользователь не подключит ПК к чужому облачному управлению одним кликом.

### Защита учётных данных (LSA, NTLM)

- **Базовая защита учётных данных: без LM-хэшей, без анонимного доступа, без WDigest, SEHOP** (`lsa.baseline`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  LM-хэши не хранятся; учётные записи с пустым паролем только для консольного входа; анонимное перечисление ресурсов и учётных записей запрещено; пароли не хранятся в памяти открытым текстом (WDigest); включена защита от перезаписи цепочки обработчиков исключений (SEHOP).
  Эффект: Украденный хэш или дамп памяти становятся малополезными.
  Риск: Очень старые устройства (принтеры, NAS), ищущие общие ресурсы анонимно, могут их не увидеть.
- **Защита LSA (RunAsPPL): LSASS как защищённый процесс** (`lsa.protection`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Память LSASS недоступна другим процессам даже с правами администратора; извлечь хэши и пароли нельзя.
  Эффект: Mimikatz и дампы через Диспетчер задач не работают. Значение 2 без привязки к UEFI: откат возможен через реестр.
  Риск: Плагины, загружаемые в LSA (драйверы токенов ЭЦП, сторонние поставщики входа), должны быть подписаны Microsoft; неподписанные не загрузятся (события 3033/3063). Проверить ключи ЭЦП организации до массового внедрения.
- **Только NTLMv2 (отказ от LM и NTLMv1)** (`lsa.ntlmv2-only`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Клиент и сервер используют только NTLMv2 и отвергают LM и NTLMv1.
  Эффект: Перехваченные хэши нельзя использовать в старых атаках на NTLMv1; современные ПК и NAS этого не замечают.
  Риск: Очень старые NAS, принтеры со сканированием в папку и встраиваемые устройства с NTLMv1 перестанут подключаться. Ослаблять вместе с правилами SMB после инвентаризации.

### Удалённый доступ

- **Удалённый помощник выключен** (`remote.assistance-off`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Приглашения удалённого помощника (msra.exe) и полный удалённый контроль запрещены.
  Эффект: Один из встроенных каналов удалённого управления закрыт; для поддержки своим администратором нужен выбранный организацией инструмент.
- **Входящий удалённый рабочий стол выключен** (`remote.rdp-inbound-off`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Входящие подключения RDP запрещены (умолчание Windows, закреплено явно); исходящие подключения к другим ПК работают.
  Эффект: Один из главных векторов атак на малые сети закрыт.
- **Проверка подлинности на уровне сети (NLA) для RDP** (`remote.rdp-nla`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Если RDP когда-нибудь включат, подключение потребует проверку подлинности до показа экрана входа.
  Эффект: Защита от атак на экран входа RDP (BlueKeep и подобные).
- **Служба удалённого реестра отключена** (`remote.registry-off`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Удалённое чтение и запись реестра невозможны.
  Эффект: На клиентских Windows служба и так отключена; закрепляется явно. Старые агенты инвентаризации могут требовать её включения.

### Шифрование диска

- **Запретить автоматическое шифрование устройства (BitLocker без ключа)** (`encryption.prevent-auto-bitlocker`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Windows не шифрует системный диск автоматически. Без домена и учётной записи Microsoft ключ восстановления некуда сохранить.
  Эффект: Клонирование и восстановление диска работают; при сбое TPM данные не теряются. Защита ноутбука от кражи включается осознанно с сохранением ключа.
  Риск: Данные на украденном ноутбуке не защищены шифрованием, пока BitLocker не включён вручную.

## Сеть и общий доступ

SMB, подпись, разрешение имён, брандмауэр.

- **SMB1 отключён и удалён** (`network.smb1-off`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Сервер не отвечает по SMB1, клиентский драйвер отключён, компонент SMB1Protocol удалён, если установлен.
  Эффект: Протокол 1996 года, через который распространялись WannaCry и NotPetya, отсутствует полностью.
  Риск: Устройства только с SMB1 (МФУ со сканированием в сетевую папку до 2015 года, старые NAS, Windows XP) не подключатся. Решение: прошивка с SMB2/3, сканирование на FTP или e-mail.
- **Подпись SMB обязательна (сервер и клиент)** (`network.smb-signing`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Каждый пакет SMB подписан; ретрансляция NTLM и подмена трафика общих папок невозможны.
  Эффект: ПК рабочей группы, настроенные этим файлом, совместимы между собой; производительность на гигабите падает на несколько процентов.
  Риск: Старые NAS и МФУ без поддержки подписи SMB2 не подключатся. Ослаблять вместе с правилами SMB1 и NTLMv2 после инвентаризации.
- **LLMNR выключен (защита от подмены имён в сети)** (`network.llmnr-off`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Широковещательный опрос имён LLMNR отключён; инструменты класса Responder не получают хэши от этих ПК.
  Эффект: Имена компьютеров рабочей группы продолжают разрешаться через NetBIOS (оставлен включённым) и mDNS.
- **NetBIOS over TCP/IP выключен** (`network.netbios-off`). Уровень: рискованное. «Офис»: выключено; «Строгий»: включено.
  Закрывает второй канал подмены имён (NBT-NS) и порты 137-139 на всех текущих интерфейсах.
  Эффект: Без домена и WINS имя вида \\PC-NAME разрешается только через mDNS (pc-name.local) или DNS маршрутизатора; привычные ярлыки на общие папки могут перестать работать.
  Риск: Интерфейсы, добавленные после установки (новый Wi-Fi адаптер, VPN), получат умолчание. Включать только после проверки в конкретной сети.
- **Брандмауэр включён на всех профилях, входящие блокируются, журнал отброшенных пакетов** (`network.firewall`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Политика для доменного, частного и общедоступного профилей: брандмауэр включён и не выключается из Панели управления, входящие по умолчанию блокируются, исходящие разрешены, отброшенные пакеты пишутся в файл 16 МБ.
  Эффект: Разрешающие правила (общий доступ к файлам и принтерам, Delivery Optimization, mDNS) продолжают работать; при расследовании видно, кто стучался на какие порты.
  Риск: Профиль сети (частная/общедоступная) файлом не задаётся; общий доступ к папкам требует частного профиля.

## Носители и скрипты

Автозапуск, скриптовые файлы, VBScript.

- **Автозапуск и автовоспроизведение выключены для всех носителей** (`removable.autorun-off`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Автозапуск отключён для всех типов дисков, файлы autorun.inf игнорируются даже на CD, автовоспроизведение выключено для устройств без буквы диска (телефоны, камеры).
  Эффект: Подключение флешки, диска или телефона ничего не запускает и ничего не спрашивает. Запуск файла вручную покрывает правило ASR для USB.

### Скриптовые файлы

- **Скриптовые файлы (.js .vbs .hta и другие) открываются в Блокноте** (`scripts.open-in-notepad`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Двойной щелчок по .js, .jse, .vbs, .vbe, .wsf, .wsh, .hta показывает текст в Блокноте, а не выполняет его.
  Эффект: Классический фишинг «архив со скриптом внутри» (счёт.pdf.js) не срабатывает. cscript, wscript и mshta из командной строки и из программ работают.
  Риск: Установщики, запускающие .vbs через оболочку (редко), откроют Блокнот. Ассоциация в профиле пользователя (Открыть с помощью) перекрывает эту.
- **Удалить движок VBScript** (`scripts.remove-vbscript`). Уровень: рискованное. «Офис»: выключено; «Строгий»: включено.
  Интерпретатор VBScript удаляется как необязательный компонент.
  Эффект: Ни .vbs, ни макросы на VBScript в старых программах, ни компонент MSScriptControl не работают.
  Риск: Установщики программ 2000-х, часть драйверов принтеров и старые корпоративные приложения используют VBScript. Ассоциация на Блокнот даёт большую часть защиты без поломок.

## Браузеры

Политики Microsoft Edge, Google Chrome и Brave: защита, телеметрия, реклама, ИИ-функции. По умолчанию включена часть политик: телеметрия, реклама, ИИ-функции, перевод страниц, автозаполнение карт, кошелёк и VPN Brave; синхронизация, вход в браузер и менеджеры паролей выключены. Политики неустановленного браузера ни на что не влияют.

### Microsoft Edge

## Журналирование для расследований

- **Аудит: создание процессов с командной строкой, входы, блокировки, учётные записи, съёмные носители** (`logging.audit-policy`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.

  Эффект: Значение из списка заказчика. Это не телеметрия: расширения улучшают работу диктора в программах.
  Риск: Диктор хуже работает в Excel и Outlook: важно для незрячих сотрудников.

### Microsoft Office

- **Office: выключить дополнительные необязательные подключённые возможности** (`office.optional-connected-off`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.

  Office не загружает из интернета шаблоны, значки, изображения, облачные шрифты и справку.
  Эффект: Меньше обращений Office к серверам Microsoft. Это не ИИ, поэтому правило выключено по умолчанию.
  Риск: Нет онлайн-шаблонов, значков, стоковых изображений, облачных шрифтов и справки F1.
- **Office: не отправлять диагностические данные** (`office.telemetry-off`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Уровень диагностических данных Office «Не отправлять»: ни обязательные, ни необязательные данные не уходят в Microsoft.
  Эффект: Остаются только служебные данные, без которых Office не работает.
- **Office: без отзывов и опросов** (`office.feedback-off`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Кнопка отправки отзыва и опросы в приложениях Office выключены.
  Эффект: Снимки экрана, журналы и фрагменты содержимого (в том числе запросы к Copilot) не уходят в Microsoft вместе с отзывами.
- **Office: флажок «Включить Copilot» снят в Word, Excel и OneNote** (`office.copilot-checkbox-off`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Пользовательские настройки Copilot в Word, Excel и OneNote выключены заранее: значения EnableCopilot из списка заказчика.
  Эффект: Флажок «Включить Copilot» в параметрах приложений есть только при входе в Office с личной учётной записью Microsoft. ### OneDrive

Политики клиента OneDrive: перенос папок в облако, сетевой трафик, отзывы, полный запрет.

- **OneDrive: запретить перенос папок пользователя в облако** (`onedrive.kfm-block`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Пользователи не могут перенести «Рабочий стол», «Документы» и «Изображения» в OneDrive (ни в рабочий, ни в личный), резервное копирование папок в параметрах OneDrive недоступно.
  Эффект: Рабочие файлы остаются на компьютере и не попадают в личное облако сотрудника. На ПК в домене Microsoft запрещает перенос в личный OneDrive сама, в рабочей группе нужна эта политика.
- **OneDrive: не выходить в сеть до входа пользователя** (`onedrive.no-traffic-before-signin`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  Клиент OneDrive не обращается к серверам Microsoft (в том числе за обновлениями), пока пользователь не вошёл в OneDrive.
  Эффект: Без учётной записи OneDrive компьютер не шлёт OneDrive никакого трафика.
  Риск: Значение продолжает действовать и после удаления политики (так описано в документации Microsoft).
- **OneDrive: без отзывов, опросов и обращений в поддержку** (`onedrive.feedback-off`). Уровень: необязательное. «Офис»: включено; «Строгий»: включено.
  В приложении OneDrive выключены отправка отзывов, опросы и связь со службой поддержки Microsoft.
  Эффект: Журналы и снимки экрана не уходят в Microsoft вместе с отзывами.
- **OneDrive: запретить использование полностью** (`onedrive.block`). Уровень: необязательное. «Офис»: выключено; «Строгий»: выключено.
  OneDrive нельзя использовать для хранения файлов: приложение, проводник и приложения Store не открывают OneDrive, синхронизация и загрузка фотографий не работают.
  Эффект: Даже заново установленный OneDrive не синхронизирует файлы. Выключено по умолчанию: это решение организации, а не настройка ИИ или телеметрии.
  Риск: Пользователи, которым OneDrive нужен для работы, теряют к нему доступ на этом компьютере.
- **OneDrive: запретить синхронизацию личного OneDrive** (`onedrive.personal-sync-off`). Уровень: необязательное. «Офис»: выключено; «Строгий»: выключено.
  Пользователь не может подключить к OneDrive личную учётную запись Microsoft.
  Эффект: Рабочие файлы не попадают в личное облако сотрудника; рабочий OneDrive (Entra ID) остаётся доступным.
  Риск: Сотрудники, которые хранят рабочие файлы в личном OneDrive, потеряют синхронизацию.

  Эффект: Дополняет машинную политику автозапуска.
- **Регион пользователя** (`default-user.region`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Страна (GeoID) для новых пользователей: влияет на Store, погоду и предложения контента; не меняет язык интерфейса и часовой пояс.
  Эффект: По умолчанию Украина (241, UA).
- **Клавиши переключения языка ввода и раскладки клавиатуры** (`default-user.input-switch-keys`). Уровень: необязательное. «Офис»: выключено; «Строгий»: выключено.
  Сочетания клавиш, которые переключают языки ввода (например ENG, UKR, RUS) и раскладки одного языка, для экрана входа и каждой учётной записи, созданной после установки. Win+Пробел работает всегда, его изменить нельзя.
  Эффект: В файле ответов нет параметра для этих клавиш, поэтому правило пишет их в реестр. Без правила Windows оставляет свои клавиши (ALT слева + SHIFT для языков, CTRL + SHIFT для раскладок). Пользователь может изменить их в Параметрах; уже существующие учётные записи не меняются.
  Риск: «Не назначено» для языков оставляет только Win+Пробел и индикатор языка на панели задач, а люди, которые о них не знают, могут их не найти. CTRL + SHIFT для языков может случайно сменить язык в программах, где есть свои сочетания с Ctrl+Shift.

## Первый вход каждого пользователя

Скрипт Active Setup: язык интерфейса и список языков ввода.

- **Закрепить язык интерфейса равным языку образа** (`user-logon.pin-ui-language`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Set-WinUILanguageOverride фиксирует язык интерфейса равным установленному, чтобы перестановка языков ввода (английский первым) не переключила интерфейс.
  Эффект: Требование заказчика «язык интерфейса не менять» держится на этой строке.
- **Список языков ввода пользователя из профиля (включая «Русский (Украина)»)** (`user-logon.input-languages`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Заменяет список языков ввода пользователя на список из узла «Языки и регион» (по умолчанию en-US, uk-UA, ru-UA). Языки без числового кода, такие как «Русский (Украина)», задать в XML нельзя, поэтому они применяются здесь; если Windows не назначила им раскладку, применяется запасной список, где они заменены базовым языком.
  Эффект: В переключателе языков пользователя тот же порядок, что в профиле; экран входа сохраняет список из XML (с базовым языком вместо «Русский (Украина)»).

## После первичной настройки

Задача планировщика после завершения OOBE: пароли, встроенные учётные записи, очистка.

- **Флаг «срок действия пароля не ограничен» на стартовых учётных записях** (`post-oobe.password-never-expires`). Уровень: рекомендуемое. «Офис»: включено; «Строгий»: включено.
  Для каждой учётной записи, которую создаёт файл ответов, устанавливается PasswordNeverExpires. Дублирует машинную настройку net accounts на случай, если её изменят.
  Эффект: Стартовые учётные записи без пароля не получат требование сменить пароль. Учётную запись, введённую при установке (режим «Спросить учётную запись при установке»), покрывает только машинная настройка.
- **Встроенные Администратор и Гость остаются отключёнными** (`post-oobe.disable-builtin-accounts`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Учётные записи с RID 500 и 501 находятся по SID (имена локализованы на украинском образе) и отключаются, если включены.
  Эффект: Известные всем имена не могут использоваться для входа.
- **Перенести ошибки прохода specialize в лог** (`post-oobe.collect-specialize-errors`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Если обёртки команд specialize записали ошибку (скрипт не извлёкся или упал), её текст попадает в Post-OOBE.log с пометкой SPECIALIZE ERROR.
  Эффект: Единственный способ узнать, что скрипт машины не выполнился.
- **Удалить копии файла ответов из системы** (`post-oobe.delete-answer-file-copies`). Уровень: базовое. «Офис»: включено; «Строгий»: включено.
  Windows 11 24H2 оставляет копии файла ответов (с именами учётных записей и паролями, если они были) в C:\Windows\Panther; они удаляются.
  Эффект: На диске не остаётся описания учётных записей.
