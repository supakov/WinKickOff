# Быстрый старт

Этот же порядок показывает узел «Порядок работы» в начале дерева программы.

## 1. Профиль

Поле «Профиль» на панели сверху. «Пресет: Офис» основан на проверенном файле ответов v0.2: защита,
обновления, печать, стартовые учётные записи Admin и User, языки ввода английский, украинский и
«Русский (Украина)». «Пресет: Строгий» добавляет ограничения, которые могут мешать старым программам.
Пресеты не перезаписываются: изменённый профиль сохраняется под своим именем.

## 2. Правила

Дерево слева содержит все настройки установки, сгруппированные по направлениям. Квадрат перед названием
включает или выключает правило или всю группу; «+» только раскрывает ветку. Счётчик у группы показывает,
сколько правил включено.

Правила связаны. Если выключить правило, от которого зависят другие, они выключатся вместе с ним; если
включить правило, включится то, что ему нужно. Что изменилось автоматически, видно в строке состояния
и в списке внизу окна. Правила, отличающиеся от настроек по умолчанию, выделены цветом.

Поиск (Ctrl+F) ищет по названию, тегам и техническим деталям, например по имени ключа реестра или службы.
Esc сбрасывает поиск. Пробел переключает выбранное правило.

## 3. Описание и параметры

Справа для выбранного правила показано: что оно делает технически (ключи реестра, службы, команды),
эффект, риски, версии Windows, зависимости, как проверить после установки и как откатить. Зависимости
кликабельны и ведут к связанным правилам. «Карточка справочника» открывает подробное техническое описание.

У некоторых правил есть параметры (время блокировки экрана, режимы защиты). Они меняются под описанием;
изменённое значение помечается словом «изменено». Кнопка «Вернуть значения по умолчанию» отменяет изменения.

## 4. Данные установки

Узлы в начале дерева:

- «Установка»: редакция Windows и ключ продукта (универсальный ключ, свой ключ или выбрать редакцию при
  установке), часовой пояс. Кроме Pro и Education, универсальные ключи списка являются ключами клиента KMS: без
  сервера KMS организации Windows не активируется, пока после установки не введён ключ лицензии. Выбранная редакция
  должна быть на установочном носителе.
- «Учётные записи»: стартовые учётные записи, их группы и описания, или «Спросить учётную запись при установке»:
  тогда установщик Windows сам спросит имя одной учётной записи администратора.
- «Языки и регион»: язык интерфейса (равен языку образа), форматы, кодовая страница и список языков
  ввода с порядком.

## 5. Сохранение профиля

«Сохранить» (Ctrl+S) записывает профиль в папку `profiles` рядом с программой. Профиль нужен, чтобы
повторять ту же установку на других компьютерах и позже вносить изменения. Меню «Файл, Недавние»
открывает последние профили и файлы. При следующем запуске программа открывает профиль, с которым её
закрыли.

## 6. Проверка и сборка

«Проверить» (F7) проверяет профиль и файл, который получится, и показывает ошибки и предупреждения
в списке внизу; двойной щелчок по сообщению ведёт к правилу или полю.

«Собрать autounattend.xml» (F9) собирает файл только из включённых правил, проверяет ограничения
установщика Windows и синтаксис скриптов PowerShell и предлагает, куда сохранить (по умолчанию папка
`output`). Имя файла должно быть `autounattend.xml`: установщик ищет только его.

## 7. Установка

Скопируйте `autounattend.xml` в корень флешки с установочным образом Windows 11 и загрузите компьютер
с неё. Подробности и проверка результата: [Установка и проверка](install-and-check.md).
