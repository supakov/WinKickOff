# Безопасность

## Сначала виртуальная машина

Каждый новый или изменённый файл ответов сначала устанавливается на виртуальную машину. Только после
проверки по документу «Установка и проверка» файл используют на рабочих компьютерах. Установка стирает
выбранный раздел диска: на компьютере с данными выбирайте раздел внимательно.

## Стартовые учётные записи без паролей

Admin (администратор) и User (обычный пользователь) создаются без паролей. Это осознанное решение:
пароли и группы назначает отдельный проект после установки. До назначения паролей:

- User не может подтвердить запрос контроля учётных записей данными Admin (Windows не принимает пустой
  пароль нигде, кроме входа за самим компьютером); программы устанавливают из-под Admin;
- общие папки между компьютерами не работают: Windows не пускает по сети с пустым паролем.

Пароль, заданный в программе, записывается в файл ответов открытым текстом. Такой файл и профиль храните
как секрет. Копии файла ответов удаляются с установленного компьютера через две минуты после первичной
настройки.

## Правила с риском

Правила уровня «рискованное» выделены в дереве цветом, а проверка (F7) предупреждает о каждом включённом.
Выключение правил уровня «базовое» тоже даёт предупреждение: они составляют основу защиты.

## Язык интерфейса и раскладки

Язык интерфейса Windows берётся из установочного образа и не меняется. Правило языков ввода меняет
только список раскладок каждого пользователя при первом входе. Если после первого входа раскладки не
такие, как ожидалось, посмотрите журнал `Setup-User.<имя>.log` и исправьте список в «Параметрах»
Windows (раздел языков); другие настройки системы это правило не трогает.

## Компьютер, на котором работает WinKickOff

Программа ничего не меняет в компьютере, на котором запущена: не пишет в реестр, не ставит службы, не
выходит в интернет. Все её файлы (профили, собранные файлы, журнал, настройки) лежат в её собственной папке.
