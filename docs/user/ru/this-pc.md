# Проверка и применение на работающем компьютере

Меню «Этот ПК» и правый щелчок по правилу или группе в дереве позволяют проверить уже установленную
Windows и при необходимости донастроить её без переустановки. Сначала выберите в дереве правило или группу.

## Проверить выбранное на этом ПК

Проверка только читает: реестр, типы запуска служб, компоненты, приложения. Она ничего не меняет и
работает без прав администратора; без них часть проверок (компоненты, приложения других пользователей)
помечается как «не проверяется». Результат по каждому правилу появляется в списке внизу окна:
«действует», «не действует» (с текущим и нужным значением), «действует частично», «не проверяется».
Значения профиля пользователя по умолчанию проверяются у текущего пользователя.

## Прочитать настройки этого ПК в новый профиль

Пункт меню «Этот ПК», «Прочитать настройки этого ПК в новый профиль...», переносит состояние компьютера в профиль.
Так можно настроить образцовый компьютер и установить по его профилю другие, или изучить повреждённую либо
заражённую систему: какие защиты на ней не действуют и что стоит на их месте.

Чтение только читает, как проверка выше, и ничего на компьютере не меняет. Читаются все правила, которые может
показать работающая Windows, встроенные и импортированные: действующее правило включается с параметрами, найденными
на компьютере (например, время блокировки экрана); правило, которое действует частично, выключается и называется в
списке внизу окна, чтобы вы решили сами; недействующее выключается. Правила, которые работают только при установке
или при первом входе, и проверки, которые без прав администратора недоступны, сохраняют состояние открытого
профиля. Формы данных получают редакцию, часовой пояс, языки и локальные учётные записи (без паролей). Имя
компьютера в профиль не переносится, чтобы установленные по нему компьютеры не получили одно имя.

С правами администратора («Прочитать настройки этого ПК с правами администратора в новый профиль...») Windows
один раз просит подтвердить права, само чтение идёт скрыто и по-прежнему ничего не меняет; тогда читаются и
дополнительные компоненты, возможности и приложения всех пользователей.

Результат открывается как новый профиль с несохранёнными изменениями: проверьте его («Проверить», F7) и сохраните
под своим именем. Значения прочитаны с этого компьютера; на повреждённой или заражённой системе они могут быть любыми,
поэтому перед сборкой просмотрите их.

## Сохранить скрипт применения

«Сохранить скрипт применения выбранного...» создаёт папку с тремя файлами:

| Файл | Назначение |
|---|---|
| `Apply.ps1` | Приводит компьютер в соответствие с профилем для выбранного: правила с галкой применяются, правила без галки возвращаются к значениям Windows по умолчанию. Запускается от имени администратора. Перед каждым изменением реестра, службы или компонента сохраняет прежнее значение в `backup-*.json` и пишет журнал `apply-*.log` рядом с собой |
| `Undo-Apply.ps1` | Возвращает прежние значения из последней резервной копии |
| `README.txt` | Порядок запуска, список правил, что не применяется и что не откатывается |

Скрипт можно отнести на другой компьютер. Сначала проверьте его на тестовом компьютере или виртуальной машине.

## Применить сейчас

«Применить выбранное сейчас...» при первом использовании спрашивает разрешение менять этот компьютер
(с предупреждением); ответ запоминается в пункте «Разрешить применение на этом ПК» меню «Этот ПК», там же
разрешение можно снять. Перед запуском программа показывает имя компьютера, число правил, что не
откатывается автоматически и нужна ли перезагрузка; затем Windows запрашивает права администратора.
Журнал и резервная копия сохраняются в папке `logs` программы.

## Вернуть к умолчаниям Windows

«Вернуть выбранное к умолчаниям Windows сейчас...» отменяет выбранные правила на этом компьютере: значения
возвращаются к тем, что стоят в чистой Windows, независимо от того, пришли правила с установкой или были
применены позже. Политики просто удаляются, остальные значения и типы запуска служб берутся из каталога.
Правила, которые зависят от выбранных, возвращаются вместе с ними. Разрешение, подтверждение и права
администратора запрашиваются так же, как при применении; прежние значения сохраняются в резервную копию,
и `Undo-Apply.ps1` из папки `logs\revert-*` отменяет возврат.

Не возвращаются автоматически: удалённые приложения и компоненты, шаги на PowerShell и значения, для
которых умолчание Windows зависит от сборки (например, подпись SMB). Они перечисляются в списке внизу окна.

## Что не применяется

- Правила, которые действуют только при установке Windows (обход проверок, экраны первичной настройки).
- Правила первого входа пользователя, в том числе список языков ввода: изменение раскладок на работающей
  системе может нарушить их переключение. По той же причине здесь не меняются клавиши переключения языка ввода:
  это правило меняет и экран входа.
- Правила без галки, для которых значения Windows по умолчанию неизвестны (удаление приложений, шаги на PowerShell):
  они перечисляются в списке внизу окна. Остальные правила без галки возвращаются к умолчаниям Windows вместе
  с правилами, которые от них зависят; правила, от которых зависят выбранные, добавляются автоматически.
- Если среди выбранного применять нечего, программа говорит об этом отдельным окном со списком причин.

Удаление приложений и компонентов, а также шаги на PowerShell автоматически не откатываются: в описании
каждого правила есть раздел «Откат». После применения перезагрузите компьютер.
