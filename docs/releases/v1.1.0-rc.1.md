# WinKickOff 1.1.0-rc.1

## Русский

Первый кандидат версии 1.1. Новое после 1.0.0-rc.4: импорт шаблонов политик ADMX.

- Меню «ADMX»: «Импортировать шаблоны этой Windows» читает `C:\Windows\PolicyDefinitions` (только чтение),
  «Импортировать шаблоны из папки...» принимает скачанные шаблоны Edge, Chrome, Office и других программ.
- Импорт появляется в дереве отдельной веткой с именем вида «PolicyDefinitions 10.0.26200, 2026-09-30 13:05»,
  хранится в папке `admx` рядом с программой и доступен при следующих запусках в том же меню; флажок показывает
  или прячет ветку, отдельный пункт удаляет импорт.
- Политики выбираются галкой и попадают в файл ответов и в «Этот ПК», как обычные правила: простые с параметром
  «Состояние политики», сложные с параметрами из своих полей. Без галки политика «не задана» и ничего не меняет.
- Названия и описания берутся только из файлов ADML на языке интерфейса, иначе по-английски.
- Если политика задаёт то же значение, что встроенное правило, в описании есть ссылка на это правило; когда
  включены оба, проверка предупреждает.
- Политики со списками значений и многострочным текстом пока не импортируются; их число показывается после
  импорта. Импортированные политики WinKickOff не проверял: испытывайте их в виртуальной машине.

Встроенные правила и пресеты не менялись: файл ответов без импортированных политик такой же, как из 1.0.0-rc.4.

## Українська

Перший кандидат версії 1.1. Нове після 1.0.0-rc.4: імпорт шаблонів політик ADMX.

- Меню «ADMX»: «Імпортувати шаблони цієї Windows» читає `C:\Windows\PolicyDefinitions` (лише читання),
  «Імпортувати шаблони з папки...» приймає завантажені шаблони Edge, Chrome, Office та інших програм.
- Імпорт з'являється в дереві окремою гілкою з назвою на кшталт «PolicyDefinitions 10.0.26200, 2026-09-30 13:05»,
  зберігається в папці `admx` поруч із програмою і доступний під час наступних запусків у тому самому меню;
  прапорець показує або ховає гілку, окремий пункт видаляє імпорт.
- Політики вибираються позначкою і потрапляють у файл відповідей та в «Цей ПК», як звичайні правила: прості з
  параметром «Стан політики», складні з параметрами з власних полів. Без позначки політика «не задана» і нічого
  не змінює.
- Назви й описи беруться лише з файлів ADML мовою інтерфейсу, інакше англійською.
- Якщо політика задає те саме значення, що й вбудоване правило, в описі є посилання на це правило; коли
  увімкнено обидва, перевірка попереджає.
- Політики зі списками значень і багаторядковим текстом поки не імпортуються; їхня кількість показується після
  імпорту. Імпортовані політики WinKickOff не перевіряв: випробовуйте їх у віртуальній машині.

Вбудовані правила й пресети не змінювалися: файл відповідей без імпортованих політик такий самий, як із
1.0.0-rc.4.

## English

The first candidate of version 1.1. New since 1.0.0-rc.4: import of ADMX policy templates.

- The "ADMX" menu: "Import the templates of this Windows" reads `C:\Windows\PolicyDefinitions` (read only),
  "Import templates from a folder..." takes downloaded templates of Edge, Chrome, Office and other programs.
- An import appears in the tree as a branch of its own with a name like "PolicyDefinitions 10.0.26200,
  2026-09-30 13:05", is kept in the `admx` folder next to the program and is available at later starts in the
  same menu; a check mark shows or hides the branch, a separate item deletes the import.
- Policies are selected with a check mark and go into the answer file and "This PC" like ordinary rules: simple
  ones with the parameter "Policy state", complex ones with parameters from their fields. Without a check mark a
  policy is "not configured" and changes nothing.
- Names and descriptions come only from the ADML files in the interface language, otherwise in English.
- When a policy sets the same value as a built-in rule, its description links to that rule; when both are on,
  the check warns.
- Policies with lists of values and multi-line text are not imported yet; their number is shown after the
  import. WinKickOff has not reviewed imported policies: try them in a virtual machine.

Built-in rules and presets did not change: an answer file without imported policies is the same as with
1.0.0-rc.4.
