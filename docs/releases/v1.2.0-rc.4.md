# WinKickOff 1.2.0-rc.4

## Русский

Четвёртый кандидат версии 1.2. Изменения после 1.2.0-rc.3:

- Пресет «Домашний» (`home`) заменяет прежний четвёртый пресет с тем же набором правил: облегчённая настройка
  домашнего компьютера без набора защиты WinKickOff (Windows оставляет свои значения). Теперь это самостоятельный
  пресет WinKickOff; его описание в окне и в документации переписано по фактическому составу правил. Если последним
  в окне был открыт прежний четвёртый пресет, программа при запуске откроет «Офис»: выберите «Домашний» в списке.
- Из текстов правил, справки, скилла и документации убраны названия конкретных компьютеров, мест и прикладных
  программ; формулировки стали общими, смысл не изменился. Уточнено описание правила базовой настройки UAC.
- Документация больше не опирается на сторонний файл ответов: приложение с исходным файлом и его разбор удалены,
  эталон v0.2 и отчёт критика по нему остались.

Действия правил и шаблоны не менялись: файлы ответов из пресетов «Офис», «Строгий» и «Ноутбук» такие же, как из
1.2.0-rc.3.

## Українська

Четвертий кандидат версії 1.2. Зміни після 1.2.0-rc.3:

- Пресет «Домашній» (`home`) замінює колишній четвертий пресет із тим самим набором правил: полегшене налаштування
  домашнього комп'ютера без набору захисту WinKickOff (Windows залишає свої значення). Тепер це самостійний пресет
  WinKickOff; його опис у вікні та в документації переписано за фактичним складом правил. Якщо останнім у вікні був
  відкритий колишній четвертий пресет, програма під час запуску відкриє «Офіс»: виберіть «Домашній» у списку.
- З текстів правил, довідки, скіла й документації прибрано назви конкретних комп'ютерів, місць і прикладних програм;
  формулювання стали загальними, зміст не змінився. Уточнено опис правила базового налаштування UAC.
- Документація більше не спирається на сторонній файл відповідей: додаток із вихідним файлом і його розбір видалено,
  еталон v0.2 і звіт критика щодо нього залишилися.

Дії правил і шаблони не змінювалися: файли відповідей із пресетів «Офіс», «Строгий» і «Ноутбук» такі самі, як із
1.2.0-rc.3.

## English

The fourth candidate of version 1.2. Changes since 1.2.0-rc.3:

- The "Home" preset (`home`) replaces the former fourth preset with the same set of rules: a lighter setup of a home
  computer without the WinKickOff protection set (Windows keeps its own defaults). It is now a WinKickOff preset of its
  own; its description in the window and in the documentation was rewritten from the rules it actually contains. If
  the former fourth preset was the last one open in the window, the program opens "Office" at start: choose "Home" in
  the list.
- Names of specific computers, places and business programs were removed from the rule texts, the help, the skill and
  the documentation; the wording is general now and the meaning is the same. The description of the basic UAC rule
  was corrected.
- The documentation no longer builds on a third-party answer file: the appendix with the original file and its review
  were removed; the v0.2 reference and the critic's report on it stay.

Rule actions and templates did not change: the answer files of the "Office", "Strict" and "Laptop" presets are the
same as with 1.2.0-rc.3.
