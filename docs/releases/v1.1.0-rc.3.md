# WinKickOff 1.1.0-rc.3

## Русский

Третий кандидат версии 1.1. Новое после 1.1.0-rc.2:

- Кнопки «Назад» и «Вперёд» над описанием правила (и Alt+Влево, Alt+Вправо): история переходов по ссылкам между
  правилами, по сообщениям внизу окна и щелчкам в дереве, как в браузере.
- Импортированное дерево можно переименовать: кнопка «Переименовать...» у корня ветки или пункт меню «ADMX». Своё
  имя сохраняется при обновлении импорта.
- Исправлено: повторный импорт тех же шаблонов давал почти пустое второе дерево. Теперь политика, которая есть в
  нескольких деревьях, показывается в каждом, а галка и параметры у неё общие.
- При импорте уже импортированной папки программа спрашивает: обновить прежний импорт (ветка и выбор в профилях
  остаются) или добавить ещё одно дерево.

Встроенные правила, пресеты и каталог 0.5 не менялись: файл ответов такой же, как из 1.1.0-rc.2.

## Українська

Третій кандидат версії 1.1. Нове після 1.1.0-rc.2:

- Кнопки «Назад» і «Вперед» над описом правила (і Alt+Ліворуч, Alt+Праворуч): історія переходів за посиланнями
  між правилами, за повідомленнями внизу вікна і клацаннями в дереві, як у браузері.
- Імпортоване дерево можна перейменувати: кнопка «Перейменувати...» біля кореня гілки або пункт меню «ADMX».
  Власна назва зберігається під час оновлення імпорту.
- Виправлено: повторний імпорт тих самих шаблонів давав майже порожнє друге дерево. Тепер політика, яка є в
  кількох деревах, показується в кожному, а позначка й параметри в неї спільні.
- Під час імпорту вже імпортованої папки програма запитує: оновити попередній імпорт (гілка і вибір у профілях
  залишаються) чи додати ще одне дерево.

Вбудовані правила, пресети й каталог 0.5 не змінювалися: файл відповідей такий самий, як із 1.1.0-rc.2.

## English

The third candidate of version 1.1. New since 1.1.0-rc.2:

- "Back" and "Forward" buttons above the description of a rule (and Alt+Left, Alt+Right): the history of jumps by
  links between rules, by messages at the bottom of the window and clicks in the tree, as in a browser.
- An imported tree can be renamed: the "Rename..." button at the root of the branch or the "ADMX" menu. A name of
  your own is kept when the import is updated.
- Fixed: a second import of the same templates gave an almost empty second tree. Now a policy found in several
  trees is shown in each of them, with one shared check mark and set of parameters.
- An import of a folder that is already imported asks whether to update the earlier import (its branch and the
  choices in profiles stay) or to add one more tree.

Built-in rules, presets and catalog 0.5 did not change: the answer file is the same as with 1.1.0-rc.2.
