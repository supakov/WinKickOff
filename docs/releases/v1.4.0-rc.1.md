# WinKickOff 1.4.0-rc.1

## Русский

Первый кандидат версии 1.4. Изменения после 1.3.0-rc.2:

- Чтение настроек компьютера в профиль: пункт меню «Этот ПК», «Прочитать настройки этого ПК в новый профиль...».
  Программа только читает этот компьютер: все правила, которые может показать работающая Windows (встроенные и
  импортированные), а также редакцию, часовой пояс, языки и локальные учётные записи без паролей. Действующее правило
  включается с параметрами, найденными на компьютере; действующее частично выключается и называется в списке внизу
  окна; недействующее выключается. Правила, которые работают только при установке или при первом входе, сохраняют
  состояние открытого профиля, имя компьютера не переносится. Результат открывается как новый профиль: проверьте его и
  сохраните под своим именем. Так удобно клонировать образцовый компьютер или изучать повреждённую или заражённую
  систему.
- Сервер MCP: инструмент `read_this_pc` читает компьютер так же и возвращает помощнику, какие защиты действуют, какие
  нет и что найдено на их месте; в режиме изменения профиля он может открыть прочитанное как новый профиль. Он
  работает только с отдельным разрешением «Разрешить чтение настроек этого ПК» в меню «MCP» или с ключом `--read-pc`
  сервера без окна; разрешение не сохраняется и при каждом запуске выключено. Других действий с компьютером через MCP
  по-прежнему нет. Контейнер `pi-agent` знает новый инструмент; образ стоит пересобрать.
- Версия каталога 0.8: проверка на этом ПК умеет читать формы данных; правила и файл ответов не изменились, профиль,
  сохранённый с каталогом 0.7, открывается с обычным предупреждением о версии каталога.

## Українська

Перший кандидат версії 1.4. Зміни після 1.3.0-rc.2:

- Читання налаштувань комп'ютера в профіль: пункт меню «Цей ПК», «Прочитати налаштування цього ПК у новий
  профіль...». Програма лише читає цей комп'ютер: усі правила, які може показати працююча Windows (вбудовані й
  імпортовані), а також випуск, часовий пояс, мови й локальні облікові записи без паролів. Правило, що діє,
  вмикається з параметрами, знайденими на комп'ютері; правило, що діє частково, вимикається й називається в списку
  внизу вікна; правило, що не діє, вимикається. Правила, які працюють лише під час інсталяції або під час першого
  входу, зберігають стан відкритого профілю, ім'я комп'ютера не переноситься. Результат відкривається як новий
  профіль: перевірте його та збережіть під своїм іменем. Так зручно клонувати зразковий комп'ютер або вивчати
  пошкоджену чи заражену систему.
- Сервер MCP: інструмент `read_this_pc` читає комп'ютер так само й повертає помічникові, які захисти діють, які ні й
  що знайдено на їхньому місці; у режимі зміни профілю він може відкрити прочитане як новий профіль. Він працює лише з
  окремим дозволом «Дозволити читання налаштувань цього ПК» у меню «MCP» або з ключем `--read-pc` сервера без вікна;
  дозвіл не зберігається й під час кожного запуску вимкнений. Інших дій із комп'ютером через MCP, як і раніше, немає.
  Контейнер `pi-agent` знає новий інструмент; образ варто перезібрати.
- Версія каталогу 0.8: перевірка на цьому ПК уміє читати форми даних; правила й файл відповідей не змінилися,
  профіль, збережений із каталогом 0.7, відкривається зі звичайним попередженням про версію каталогу.

## English

The first candidate of version 1.4. Changes after 1.3.0-rc.2:

- Reading the settings of a computer into a profile: the "This PC" menu item "Read the settings of this PC into a new
  profile...". The program only reads this computer: every rule a running Windows can show (built-in and imported),
  the edition, the time zone, the languages and the local accounts without passwords. A rule in effect is switched on
  with the parameters found on the computer; a rule partly in effect is switched off and named in the list at the
  bottom of the window; a rule not in effect is switched off. Rules that act only during installation or at the first
  sign-in keep the state of the open profile, and the computer name is not taken. The result opens as a new profile:
  check it and save it under a name of your own. Use it to clone a reference computer or to study a damaged or
  infected system.
- The MCP server: the tool `read_this_pc` reads the computer the same way and tells the assistant which protections
  take effect, which do not and what was found instead; in the mode that changes the profile it may open the read as
  a new profile. It works only with the separate permission "Allow reading the settings of this PC" in the "MCP" menu
  or the switch `--read-pc` of a server without a window; the permission is never saved and is off at every start.
  MCP still does nothing else with the computer. The `pi-agent` container knows the new tool; rebuild the image.
- Catalog version 0.8: the check on this PC can read the data forms; the rules and the answer file did not change,
  and a profile saved with catalog 0.7 opens with the usual warning about the catalog version.
