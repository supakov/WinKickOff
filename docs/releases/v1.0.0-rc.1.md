# WinKickOff 1.0.0-rc.1

## Русский

Первый кандидат в выпуск. WinKickOff собирает файл `autounattend.xml` для автоматической установки
Windows 11 Pro в небольших организациях без домена и проверяет или донастраивает уже установленную Windows.
Установка из собранного файла проверена заказчиком на реальных компьютерах: учётные записи создаются,
языки на месте, вопросов при установке минимум.

Что внутри:

- каталог из 177 правил в 27 группах с поиском, описаниями и зависимостями; любое правило можно выключить;
- пресеты «Офис», «Строгий», «Ноутбук» и «memstechtips» (перенос оригинала UnattendedWinstall);
- раздел «Браузеры»: политики Edge, Chrome и Brave; OneDrive не устанавливается новым пользователям;
- проверка, применение и возврат к умолчаниям Windows выбранных правил на работающем компьютере
  (меню «Этот ПК» и правый щелчок в дереве), с резервной копией и откатом;
- интерфейс на русском, украинском и английском; импорт профиля из готового файла.

Как запустить: распакуйте `WinKickOff-1.0.0-rc.1.zip` и откройте `WinKickOff.exe`. Программе не нужны права
администратора. Новый файл ответов сначала проверьте на виртуальной машине. Файл программы не подписан,
поэтому при первом запуске SmartScreen может показать предупреждение.

Ещё не проверено: применение и возврат правил на работающем компьютере на виртуальной машине заказчика.

## Українська

Перший кандидат у випуск. WinKickOff збирає файл `autounattend.xml` для автоматичного встановлення
Windows 11 Pro у невеликих організаціях без домену та перевіряє або доналаштовує вже встановлену Windows.
Встановлення з зібраного файлу перевірено замовником на реальних комп'ютерах: облікові записи створюються,
мови на місці, запитань під час встановлення мінімум.

Що всередині:

- каталог із 177 правил у 27 групах з пошуком, описами та залежностями; будь-яке правило можна вимкнути;
- пресети «Офіс», «Суворий», «Ноутбук» і «memstechtips» (перенесення оригіналу UnattendedWinstall);
- розділ «Браузери»: політики Edge, Chrome і Brave; OneDrive не встановлюється новим користувачам;
- перевірка, застосування й повернення до стандартних значень Windows вибраних правил на робочому комп'ютері
  (меню «Цей ПК» і правий клік у дереві), з резервною копією та відкатом;
- інтерфейс російською, українською та англійською; імпорт профілю з готового файлу.

Як запустити: розпакуйте `WinKickOff-1.0.0-rc.1.zip` і відкрийте `WinKickOff.exe`. Програмі не потрібні
права адміністратора. Новий файл відповідей спочатку перевірте на віртуальній машині. Файл програми не
підписано, тому під час першого запуску SmartScreen може показати попередження.

Ще не перевірено: застосування й повернення правил на робочому комп'ютері на віртуальній машині замовника.

## English

The first release candidate. WinKickOff builds an `autounattend.xml` answer file for unattended installation
of Windows 11 Pro in small organisations without a domain, and checks or fine-tunes an installed Windows.
Installation from a built file has been confirmed by the customer on real computers: the accounts are
created, the languages are in place, the installer asks almost nothing.

Inside:

- a catalog of 177 rules in 27 groups with search, descriptions and dependencies; any rule can be turned off;
- presets "Office", "Strict", "Laptop" and "memstechtips" (the original UnattendedWinstall carried over);
- the "Browsers" section: Edge, Chrome and Brave policies; OneDrive is not installed for new users;
- checking, applying and returning to Windows defaults the selected rules on a running computer ("This PC"
  menu and right click in the tree), with a backup and rollback;
- interface in Russian, Ukrainian and English; import of a profile from a built file.

How to run: unzip `WinKickOff-1.0.0-rc.1.zip` and open `WinKickOff.exe`. The program needs no administrator
rights. Test a new answer file in a virtual machine first. The program file is not signed, so SmartScreen
may show a warning at the first start.

Not verified yet: applying and returning rules on a running computer in the customer's virtual machine.
