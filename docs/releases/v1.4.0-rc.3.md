# WinKickOff 1.4.0-rc.3

## Русский

Третий кандидат версии 1.4. Изменения после 1.4.0-rc.2:

- Папка `agents` рядом с программой: готовые инструкции помощника WinKickOff для любого ИИ-агента с поддержкой MCP
  (`AGENTS.md`) и описание подключения (`README.md`). Они не привязаны к одному агенту: подходят Claude Code, Codex
  CLI, Cursor, Gemini CLI и чат-клиентам с полем для инструкций. Помощник работает с WinKickOff только через сервер
  MCP, спрашивает перед каждым изменением и умеет изучать настройки этого ПК, если чтение разрешено в меню «MCP».
  Скопируйте `AGENTS.md` в пустую папку агента под именем, которое читает ваш клиент.
- Инструкции контейнера `pi-agent` знают о 19 инструментах и о чтении настроек этого ПК.

## Українська

Третій кандидат версії 1.4. Зміни після 1.4.0-rc.2:

- Папка `agents` поруч із програмою: готові інструкції помічника WinKickOff для будь-якого ШІ-агента з підтримкою MCP
  (`AGENTS.md`) і опис підключення (`README.md`). Вони не прив'язані до одного агента: підходять Claude Code, Codex
  CLI, Cursor, Gemini CLI і чат-клієнтам із полем для інструкцій. Помічник працює з WinKickOff лише через сервер MCP,
  питає перед кожною зміною й уміє вивчати налаштування цього ПК, якщо читання дозволено в меню «MCP». Скопіюйте
  `AGENTS.md` у порожню папку агента під іменем, яке читає ваш клієнт.
- Інструкції контейнера `pi-agent` знають про 19 інструментів і про читання налаштувань цього ПК.

## English

The third candidate of version 1.4. Changes after 1.4.0-rc.2:

- The folder `agents` next to the program: ready instructions of the WinKickOff assistant for any AI agent with MCP
  support (`AGENTS.md`) and how to connect it (`README.md`). They are not tied to one agent: they suit Claude Code,
  Codex CLI, Cursor, Gemini CLI and chat clients with a field for instructions. The assistant works with WinKickOff
  only through the MCP server, asks before every change and can study the settings of this PC when reading is allowed
  in the "MCP" menu. Copy `AGENTS.md` into an empty folder of the agent under the name your client reads.
- The instructions of the `pi-agent` container know the 19 tools and the read of the settings of this PC.
