# WinKickOff 1.4.0-rc.12

## Русский

Двенадцатый кандидат версии 1.4, собран из ветки `unattend-tree` (план `docs/reports/2026-10-13-plan-unattend.md`,
этапы 6 и 7, последние в плане) для приёмки в виртуальной машине. Изменения после 1.4.0-rc.11:

- Форма «Установка», поле «Рабочая группа»: имя до 15 латинских букв, цифр и дефисов; компьютер присоединяется к ней
  при установке (JoinWorkgroup). Пустое поле оставляет WORKGROUP.
- Форма «Установка», блок «Диск»: «Установщик Windows спрашивает, куда устанавливать» (как раньше) или «Установить в
  этот раздел без вопроса» с номерами диска и раздела (ImageInstall/InstallTo). Раздел должен существовать и быть
  отформатирован, его содержимое заменяется; разметка диска не делается. Проверка профиля предупреждает об этом режиме.
- Профиль формата 5: новые поля рабочей группы и диска; профили прежних форматов открываются как раньше.
- Правило «Драйверы из папки Drivers установочного носителя» (выключено по умолчанию): при первой перезагрузке все
  пакеты `.inf` из папки `Drivers` рядом с autounattend.xml устанавливаются через pnputil. Драйвер, нужный самому
  установщику, чтобы увидеть диск, так не добавить.
- Приёмка в ВМ: имя рабочей группы в «О системе»; установка на подготовленный раздел второго диска без страницы
  выбора диска; флешка с папкой Drivers виртуального сетевого адаптера.

## Українська

Дванадцятий кандидат версії 1.4, зібраний із гілки `unattend-tree` (план `docs/reports/2026-10-13-plan-unattend.md`,
етапи 6 і 7, останні в плані) для приймання у віртуальній машині. Зміни після 1.4.0-rc.11:

- Форма «Інсталяція», поле «Робоча група»: ім'я до 15 латинських літер, цифр і дефісів; комп'ютер приєднується до неї
  під час інсталяції (JoinWorkgroup). Порожнє поле залишає WORKGROUP.
- Форма «Інсталяція», блок «Диск»: «Інсталятор Windows запитує, куди встановлювати» (як раніше) або «Встановити в цей
  розділ без запитання» з номерами диска і розділу (ImageInstall/InstallTo). Розділ має існувати і бути
  відформатованим, його вміст замінюється; розмітка диска не виконується. Перевірка профілю попереджає про цей режим.
- Профіль формату 5: нові поля робочої групи і диска; профілі попередніх форматів відкриваються як раніше.
- Правило «Драйвери з папки Drivers інсталяційного носія» (вимкнене за замовчуванням): під час першого перезавантаження
  всі пакети `.inf` з папки `Drivers` поруч з autounattend.xml встановлюються через pnputil. Драйвер, потрібний самому
  інсталятору, щоб побачити диск, так не додати.
- Приймання у ВМ: ім'я робочої групи в «Про систему»; інсталяція на підготовлений розділ другого диска без сторінки
  вибору диска; флешка з папкою Drivers віртуального мережевого адаптера.

## English

The twelfth candidate of version 1.4, built from the branch `unattend-tree` (plan `docs/reports/2026-10-13-plan-unattend.md`,
stages 6 and 7, the last of the plan) for the acceptance in a virtual machine. Changes after 1.4.0-rc.11:

- The form "Installation", field "Workgroup": a name of up to 15 Latin letters, digits and hyphens; the computer joins
  it during installation (JoinWorkgroup). An empty field leaves WORKGROUP.
- The form "Installation", block "Disk": "Windows Setup asks where to install" (as before) or "Install to this
  partition without asking" with the disk and partition numbers (ImageInstall/InstallTo). The partition must exist
  and be formatted, what is on it is replaced; the disk is not repartitioned. The profile check warns about this mode.
- Profile format 5: the new fields of the workgroup and the disk; profiles of earlier formats open as before.
- The rule "Drivers from the Drivers folder of the installation media" (off by default): at the first restart every
  `.inf` package of the `Drivers` folder next to autounattend.xml is installed with pnputil. A driver that Setup
  itself needs to see the disk cannot be added this way.
- Acceptance in a VM: the workgroup name in "About"; an installation to a prepared partition of a second disk without
  the disk page; a USB stick with a Drivers folder of a virtual network adapter.
