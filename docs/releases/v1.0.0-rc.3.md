# WinKickOff 1.0.0-rc.3

## Русский

Третий кандидат в выпуск. Исправление после 1.0.0-rc.2:

- «Применить выбранное сейчас» и «Сохранить скрипт применения выбранного» больше не пропускают молча правила без
  галки. Скрипт приводит компьютер в соответствие с профилем: правила с галкой применяются, правила без галки (и
  зависящие от них) возвращаются к значениям Windows по умолчанию. Для группы это значит: отмеченные правила
  применяются, неотмеченные откатываются. Чтобы применить одно правило, выделяйте его, а не группу.
- Если среди выбранного применять нечего, программа показывает окно со списком причин, а не только строку внизу.
- В окне подтверждения видно, сколько правил применится и сколько вернётся к умолчаниям.
- «Проверить выбранное на этом ПК» проверяет все выбранные правила, независимо от галок.

Правила и пресеты не менялись: файл ответов из этой версии такой же, как из 1.0.0-rc.2.

## Українська

Третій кандидат у випуск. Виправлення після 1.0.0-rc.2:

- «Застосувати вибране зараз» і «Зберегти сценарій застосування вибраного» більше не пропускають мовчки правила
  без позначки. Сценарій приводить комп'ютер у відповідність до профілю: правила з позначкою застосовуються, правила
  без позначки (і залежні від них) повертаються до стандартних значень Windows. Для групи це означає: позначені
  правила застосовуються, непозначені відкочуються. Щоб застосувати одне правило, виділяйте його, а не групу.
- Якщо серед вибраного застосовувати нічого, програма показує вікно зі списком причин, а не лише рядок унизу.
- У вікні підтвердження видно, скільки правил застосується і скільки повернеться до стандартних значень.
- «Перевірити вибране на цьому ПК» перевіряє всі вибрані правила, незалежно від позначок.

Правила й пресети не змінювалися: файл відповідей із цієї версії такий самий, як із 1.0.0-rc.2.

## English

The third release candidate. Fix since 1.0.0-rc.2:

- "Apply the selection now" and "Save an apply script for the selection" no longer skip rules without a check mark
  silently. The script makes the computer match the profile: rules with a check mark are applied, rules without one
  (and the rules that depend on them) return to the Windows defaults. For a group this means: checked rules are
  applied, unchecked ones are rolled back. To apply one rule, select that rule, not its group.
- When there is nothing to apply in the selection, the program shows a window with the reasons instead of a line in
  the status bar only.
- The confirmation shows how many rules are applied and how many return to the defaults.
- "Check the selection on this PC" checks every selected rule, whatever its check mark.

Rules and presets did not change: an answer file built with this version is the same as with 1.0.0-rc.2.
