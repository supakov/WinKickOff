# WinKickOff 1.4.0-rc.7

## Русский

Седьмой кандидат версии 1.4. Изменения после 1.4.0-rc.6, по разбору чтения ПК, установленного с профилем, от 12.10.2026:

- Импортированная политика, значения которой записывает включённое встроенное правило, после чтения этого ПК сохраняет
  состояние и параметры открытого профиля. Прежде чтение записывало ей значение, найденное на ПК (то, что пишет встроенное
  правило), хотя политика оставалась выключенной, и в сравнении с профилем установки 55 политик Edge и Chrome выглядели
  изменёнными только параметром.
- Правило, у которого совпало только то, что и так есть в чистой Windows (например, удаление значения, которого нет, или
  отключение функции, которой нет на этой сборке), сохраняет состояние открытого профиля, а не выключается: чтение не
  может ни подтвердить его, ни опровергнуть. Так правило удаления OneDrive больше не выключается при каждом чтении.
- Страница «Этот ПК» документации: значения профиля пользователя по умолчанию проверяются у текущего пользователя, и
  Windows могла изменить их после создания учётной записи.

## Українська

Сьомий кандидат версії 1.4. Зміни після 1.4.0-rc.6, за розбором читання ПК, встановленого з профілем, від 12.10.2026:

- Імпортована політика, значення якої записує ввімкнене вбудоване правило, після читання цього ПК зберігає стан і
  параметри відкритого профілю. Раніше читання записувало їй значення, знайдене на ПК (те, що пише вбудоване правило),
  хоча політика залишалася вимкненою, і в порівнянні з профілем інсталяції 55 політик Edge і Chrome виглядали зміненими
  лише параметром.
- Правило, у якого збіглося лише те, що й так є в чистій Windows (наприклад, видалення значення, якого немає, або
  вимкнення функції, якої немає на цій збірці), зберігає стан відкритого профілю, а не вимикається: читання не може ні
  підтвердити його, ні спростувати. Так правило видалення OneDrive більше не вимикається під час кожного читання.
- Сторінка «Цей ПК» документації: значення типового профілю користувача перевіряються в поточного користувача, і Windows
  могла змінити їх після створення облікового запису.

## English

The seventh candidate of version 1.4. Changes after 1.4.0-rc.6, from the study of a read of a PC installed from a profile
on 12.10.2026:

- An imported policy whose values an enabled built-in rule writes keeps the state and the parameters of the open profile
  after a read of this PC. Before, the read gave it the value found on the PC (what the built-in rule writes) although the
  policy stayed off, and in the comparison with the profile of the installation 55 Edge and Chrome policies looked changed
  in a parameter only.
- A rule that matches only what a clean Windows has anyway (the removal of a value that is absent, a feature this build
  does not ship) keeps the state of the open profile instead of being switched off: the read can neither confirm nor
  refute it. So the rule that removes OneDrive is no longer switched off by every read.
- The page "This PC" of the documentation: the values of the default user profile are checked for the current user, and
  Windows may have changed them since the account was made.
