# WinKickOff 1.4.0-rc.4

## Русский

Четвёртый кандидат версии 1.4. Изменения после 1.4.0-rc.3:

- Чтение настроек этого ПК больше не помечает как действующие правила, у которых совпало только то, что и так есть в
  чистой Windows (значения нет, удалённое значение, пустой список многострочных параметров импортированных политик).
  Такие правила считаются «как в Windows по умолчанию» и остаются выключенными; частично действует только правило, у
  которого найдено значение, которого нет в Windows по умолчанию.
- «Этот ПК», «Прочитать выбранное на этом ПК в открытый профиль...»: читаются только выбранные правила, группа или
  ветка импортированного каталога, и их состояние попадает в открытый профиль как несохранённые изменения; имя профиля
  и формы данных не меняются.
- Длительные операции (импорт шаблонов и файлов каталога, чтение и проверка ПК) показывают окно, которое закрывается
  само по окончании работы; запуск программы и перестройка окна после импорта показывают заставку загрузки.

## Українська

Четвертий кандидат версії 1.4. Зміни після 1.4.0-rc.3:

- Читання налаштувань цього ПК більше не позначає як чинні правила, у яких збіглося лише те, що й так є в чистій
  Windows (значення немає, видалене значення, порожній список багаторядкових параметрів імпортованих політик). Такі
  правила вважаються «як у Windows за замовчуванням» і залишаються вимкненими; частково діє лише правило, у якого
  знайдено значення, якого немає в Windows за замовчуванням.
- «Цей ПК», «Прочитати вибране на цьому ПК у відкритий профіль...»: читаються лише вибрані правила, група або гілка
  імпортованого каталогу, і їхній стан потрапляє у відкритий профіль як незбережені зміни; ім'я профілю та форми
  даних не змінюються.
- Тривалі операції (імпорт шаблонів і файлів каталогу, читання й перевірка ПК) показують вікно, яке закривається саме
  після завершення роботи; запуск програми й перебудова вікна після імпорту показують заставку завантаження.

## English

The fourth candidate of version 1.4. Changes after 1.4.0-rc.3:

- Reading the settings of this PC no longer marks as in effect the rules that match only what a clean Windows has
  anyway (no value, a deleted value, an empty list of a multi-line parameter of an imported policy). Such rules count
  as "as in Windows by default" and stay off; a rule is partly in effect only when a value was found that Windows does
  not have by default.
- "This PC", "Read the selection on this PC into the open profile...": only the selected rules, group or branch of an
  imported catalog are read, and their state goes into the open profile as unsaved changes; the profile name and the
  data forms stay.
- Long operations (imports of templates and catalog files, the read and the check of this PC) show a window that closes
  by itself when the work is done; the start of the program and the rebuild of the window after an import show a
  loading splash.
