# WinKickOff 1.4.0-rc.2

## Русский

Второй кандидат версии 1.4. Изменения после 1.4.0-rc.1:

- Чтение настроек этого ПК с правами администратора: отдельный пункт меню «Этот ПК». Windows один раз просит
  подтвердить права, чтение идёт скрыто и ничего не меняет; дополнительно читаются компоненты, возможности и
  приложения всех пользователей. Через MCP чтение по-прежнему идёт без повышения прав.
- Черновик: пока профиль не сохранён, его изменения раз в минуту и при закрытии окна записываются в черновик рядом с
  программой. Закрытие больше не спрашивает о сохранении: при следующем запуске профиль откроется с теми же
  несохранёнными изменениями.
- «Файл, Изменения после последнего сохранения...» и сравнение с профилем показывают отличия деревом с описанием
  правила. Отличия можно сохранить как дифф-профиль (`.wkdiff`, только отличия) и объединить с открытым профилем
  («Файл, Объединить с дифф-профилем...»), а также применить к этому ПК только изменённые правила.

## Українська

Другий кандидат версії 1.4. Зміни після 1.4.0-rc.1:

- Читання налаштувань цього ПК з правами адміністратора: окремий пункт меню «Цей ПК». Windows один раз просить
  підтвердити права, читання йде приховано й нічого не змінює; додатково читаються компоненти, можливості й
  застосунки всіх користувачів. Через MCP читання, як і раніше, йде без підвищення прав.
- Чернетка: поки профіль не збережено, його зміни щохвилини й під час закриття вікна записуються в чернетку поруч із
  програмою. Закриття більше не питає про збереження: під час наступного запуску профіль відкриється з тими самими
  незбереженими змінами.
- «Файл, Зміни після останнього збереження...» і порівняння з профілем показують відмінності деревом з описом
  правила. Відмінності можна зберегти як дифф-профіль (`.wkdiff`, лише відмінності) й об'єднати з відкритим профілем
  («Файл, Об'єднати з дифф-профілем...»), а також застосувати до цього ПК лише змінені правила.

## English

The second candidate of version 1.4. Changes after 1.4.0-rc.1:

- Reading the settings of this PC as administrator: a separate item of the "This PC" menu. Windows asks to confirm the
  rights once; the read runs hidden and changes nothing, and it also reads the optional features, capabilities and the
  apps of every user. Through MCP the read still runs without elevation.
- The draft: while a profile is not saved, its changes go to a draft next to the program every minute and when the
  window closes. Closing no longer asks about saving: the next start opens the profile with the same unsaved changes.
- "File, Changes since the last save..." and the comparison with a profile show the differences as a tree with the
  description of the rule. The differences can be saved as a diff profile (`.wkdiff`, only the differences), merged
  into the open profile ("File, Merge a diff profile...") and applied to this PC, the changed rules only.
