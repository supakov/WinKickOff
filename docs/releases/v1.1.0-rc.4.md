# WinKickOff 1.1.0-rc.4

## Русский

Четвёртый кандидат версии 1.1. Новое после 1.1.0-rc.3: импортированная политика следует за встроенным правилом,
которое задаёт то же значение реестра.

- Если включённое встроенное правило пишет всё, что пишет политика ADMX, политика показывается отмеченной (цветом
  ссылки) и учитывается в счётчиках групп; в описании сказано «Задано встроенным правилом», а значение показано
  таким, каким его запишет правило. Отдельно политика в файл ответов не пишется, значение не записывается дважды.
- Если политика пишет ровно то же, что встроенное правило (например, PUA, SmartScreen), галка у политики включает
  и выключает само встроенное правило.
- Если политика задаёт только часть значений встроенного правила, снятие галки спросит, выключать ли правило
  целиком.
- Политика, включённая отдельно, снимается сама, когда встроенное правило начинает писать то же значение; это
  видно в сообщениях внизу окна.

Встроенные правила, пресеты и каталог 0.5 не менялись: файл ответов такой же, как из 1.1.0-rc.3.

## Українська

Четвертий кандидат версії 1.1. Нове після 1.1.0-rc.3: імпортована політика йде за вбудованим правилом, яке задає
те саме значення реєстру.

- Якщо увімкнене вбудоване правило пише все, що пише політика ADMX, політика показується позначеною (кольором
  посилання) і враховується в лічильниках груп; в описі сказано «Задано вбудованим правилом», а значення показано
  таким, яким його запише правило. Окремо політика у файл відповідей не пишеться, значення не записується двічі.
- Якщо політика пише рівно те саме, що вбудоване правило (наприклад, PUA, SmartScreen), позначка політики вмикає
  й вимикає саме вбудоване правило.
- Якщо політика задає лише частину значень вбудованого правила, зняття позначки запитає, чи вимикати правило
  цілком.
- Політика, увімкнена окремо, знімається сама, коли вбудоване правило починає писати те саме значення; це видно
  в повідомленнях унизу вікна.

Вбудовані правила, пресети й каталог 0.5 не змінювалися: файл відповідей такий самий, як із 1.1.0-rc.3.

## English

The fourth candidate of version 1.1. New since 1.1.0-rc.3: an imported policy follows the built-in rule that sets
the same registry value.

- When an enabled built-in rule writes everything an ADMX policy writes, the policy is shown checked (in the link
  colour) and counted in its groups; its description says "Set by the built-in rule", and the value is shown as
  the rule writes it. The policy is not written into the answer file separately, so no value is written twice.
- When the policy writes exactly what the built-in rule writes (for example PUA, SmartScreen), the check mark of
  the policy switches the built-in rule itself on and off.
- When the policy sets only part of the values of the built-in rule, unchecking it asks whether to switch the
  whole rule off.
- A policy switched on by itself goes off by itself when the built-in rule starts writing the same value; the
  messages at the bottom of the window show it.

Built-in rules, presets and catalog 0.5 did not change: the answer file is the same as with 1.1.0-rc.3.
