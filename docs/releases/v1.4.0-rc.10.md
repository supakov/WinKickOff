# WinKickOff 1.4.0-rc.10

## Русский

Десятый кандидат версии 1.4, собран из ветки `unattend-tree` (план `docs/reports/2026-10-13-plan-unattend.md`, этап 3)
для приёмки в виртуальной машине. Изменения после 1.4.0-rc.9:

- Каталог 0.10: дерево правил разделено по механизму на три корня. «autounattend.xml»: правила, действующие штатными
  средствами файла ответов (установка, OOBE), и формы данных. «Штатные политики»: встроенные правила, которые пишут
  только значения политик Windows, и все импортированные шаблоны; корень неизвестных правил здесь же, невидим, когда
  пуст. «Прочее»: остальные правила (реестр вне политик, службы, функции, приложения, скрипты, профиль по умолчанию,
  первый вход, после OOBE). Тематическая группа стоит под корнем большинства своих правил, правила другого механизма
  лежат в группе с тем же названием под нужным корнем. Идентификаторы правил не менялись: профили, пресеты и
  дифф-профили прежних версий открываются как раньше.
- «Включить все» для группы больше не включает импортированные политики (корень политик содержит тысячи), только
  выключает; корни раскрыты при запуске; окно сравнения группирует отличия по тематической группе под корнем.
- Для агентов: `list_groups` без `parent` возвращает три корня; инструкции и навык обновлены.

## Українська

Десятий кандидат версії 1.4, зібраний із гілки `unattend-tree` (план `docs/reports/2026-10-13-plan-unattend.md`,
етап 3) для приймання у віртуальній машині. Зміни після 1.4.0-rc.9:

- Каталог 0.10: дерево правил розділено за механізмом на три корені. «autounattend.xml»: правила, що діють штатними
  засобами файлу відповідей (інсталяція, OOBE), і форми даних. «Штатні політики»: вбудовані правила, які пишуть лише
  значення політик Windows, і всі імпортовані шаблони; корінь невідомих правил тут само, невидимий, коли порожній.
  «Інше»: решта правил (реєстр поза політиками, служби, функції, застосунки, скрипти, типовий профіль, перший вхід,
  після OOBE). Тематична група стоїть під коренем більшості своїх правил, правила іншого механізму лежать у групі з
  тією самою назвою під потрібним коренем. Ідентифікатори правил не змінювалися: профілі, пресети та дифф-профілі
  попередніх версій відкриваються як раніше.
- «Увімкнути все» для групи більше не вмикає імпортовані політики (корінь політик містить тисячі), лише вимикає;
  корені розгорнуті під час запуску; вікно порівняння групує відмінності за тематичною групою під коренем.
- Для агентів: `list_groups` без `parent` повертає три корені; інструкції та навичку оновлено.

## English

The tenth candidate of version 1.4, built from the branch `unattend-tree` (plan `docs/reports/2026-10-13-plan-unattend.md`,
stage 3) for the acceptance in a virtual machine. Changes after 1.4.0-rc.9:

- Catalog 0.10: the rule tree is split by mechanism into three roots. "autounattend.xml": the rules that act through
  the answer file itself (installation, OOBE) and the data forms. "Standard policies": the built-in rules that write
  policy values of Windows only, and every imported template; the root of unknown rules sits there too, hidden while
  empty. "Other": the remaining rules (registry outside policies, services, features, apps, scripts, the default
  profile, the first sign-in, after OOBE). A thematic group sits under the root of most of its rules; the rules of
  another mechanism are in a group of the same name under the right root. Rule ids are unchanged: profiles, presets
  and diff profiles of earlier versions open as before.
- "Enable all" of a group no longer switches imported policies on (the policies root holds thousands), it only
  switches them off; the roots start open; the comparison window groups the differences by the thematic group under
  a root.
- For agents: `list_groups` without `parent` returns the three roots; the instructions and the skill are updated.
