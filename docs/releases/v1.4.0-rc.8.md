# WinKickOff 1.4.0-rc.8

## Русский

Восьмой кандидат версии 1.4. Изменения после 1.4.0-rc.7:

- Внутренняя перестройка без изменения поведения: модуль главного окна (3048 строк) разделён на главный модуль и пять
  модулей по областям (правая панель и параметры; профили, черновик, сравнение, проверка и сборка; меню «Этот ПК»;
  меню ADMX; меню MCP), а модуль импорта шаблонов политик (1387 строк) стал пакетом из пяти модулей. Код перенесён
  как есть, все тесты проходят без изменения логики; для пользователя программа работает так же, как 1.4.0-rc.7.

## Українська

Восьмий кандидат версії 1.4. Зміни після 1.4.0-rc.7:

- Внутрішня перебудова без зміни поведінки: модуль головного вікна (3048 рядків) розділено на головний модуль і п'ять
  модулів за областями (права панель і параметри; профілі, чернетка, порівняння, перевірка і збирання; меню «Цей ПК»;
  меню ADMX; меню MCP), а модуль імпорту шаблонів політик (1387 рядків) став пакетом із п'яти модулів. Код перенесено
  як є, усі тести проходять без зміни логіки; для користувача програма працює так само, як 1.4.0-rc.7.

## English

The eighth candidate of version 1.4. Changes after 1.4.0-rc.7:

- An internal restructuring without a change of behaviour: the module of the main window (3048 lines) is split into
  the main module and five modules by area (the right panel and parameters; profiles, draft, comparison, check and
  build; the menu "This PC"; the ADMX menu; the MCP menu), and the module that imports policy templates (1387 lines)
  became a package of five modules. The code moved as it was, every test passes with no change of logic; for the
  person the program works as 1.4.0-rc.7 did.
