# WinKickOff 1.3.0-rc.2

## Русский

Второй кандидат версии 1.3. Изменения после 1.3.0-rc.1:

- Имя компьютера в форме «Установка»: «Windows выбирает имя сама» (как раньше, `DESKTOP-` и случайные символы), «Это
  имя» или «Имя по шаблону». Имя содержит до 15 латинских букв, цифр и дефисов и не может состоять только из цифр.
  Шаблон добавляет части, которые вычисляются на каждом компьютере при установке: `{serial}` (конец серийного номера
  BIOS), `{mac}` (конец адреса сетевого адаптера), `{random}` (случайные буквы и цифры). Число задаёт длину, например
  `OFFICE-{serial:6}`. Часть, которую не удалось прочитать, заменяется случайными символами. Имя задаётся только при
  установке; меню «Этот ПК» работающий компьютер не переименовывает. Проверьте шаблон в виртуальной машине.
- Кириллица в учётных записях: установщик Windows 24H2 и новее превращает символы вне латиницы в вопросительные знаки
  (так было с описанием пользователя). Теперь отображаемое имя и описание на кириллице задаёт `Post-OOBE.ps1` после
  первичной настройки, а файл ответов содержит только латиницу. Имя учётной записи и пароль на кириллице так не
  исправить, поэтому проверка считает их ошибкой: пишите их латиницей. Другие места, где проходит кириллица (скрипты,
  журналы, скрипты меню «Этот ПК», отчёт проверки), проверены и работают правильно.
- Проверка файла ответов (`tools/Validate-Unattend.ps1`, 37 проверок) и проверка в программе сообщают об имени
  компьютера неверного вида и о символах вне ASCII в учётных записях.
- Профили сохраняются в формате 4; профили форматов 2 и 3 открываются без предупреждения, имя компьютера в них
  выбирает Windows. Версия каталога 0.7: правила не изменились, профиль, сохранённый с каталогом 0.6, открывается с
  обычным предупреждением о версии каталога.

## Українська

Другий кандидат версії 1.3. Зміни після 1.3.0-rc.1:

- Ім'я комп'ютера у формі «Інсталяція»: «Windows вибирає ім'я сама» (як раніше, `DESKTOP-` і випадкові символи), «Це
  ім'я» або «Ім'я за шаблоном». Ім'я містить до 15 латинських літер, цифр і дефісів і не може складатися лише з цифр.
  Шаблон додає частини, які обчислюються на кожному комп'ютері під час інсталяції: `{serial}` (кінець серійного
  номера BIOS), `{mac}` (кінець адреси мережного адаптера), `{random}` (випадкові літери й цифри). Число задає
  довжину, наприклад `OFFICE-{serial:6}`. Частина, яку не вдалося прочитати, замінюється випадковими символами. Ім'я
  задається лише під час інсталяції; меню «Цей ПК» не перейменовує робочий комп'ютер. Перевірте шаблон у віртуальній
  машині.
- Кирилиця в облікових записах: інсталятор Windows 24H2 і новіших перетворює символи поза латиницею на знаки питання
  (так було з описом користувача). Тепер відображуване ім'я та опис кирилицею задає `Post-OOBE.ps1` після первинного
  налаштування, а файл відповідей містить лише латиницю. Ім'я облікового запису й пароль кирилицею так не виправити,
  тому перевірка вважає їх помилкою: пишіть їх латиницею. Інші місця, де проходить кирилиця (скрипти, журнали,
  скрипти меню «Цей ПК», звіт перевірки), перевірено, і вони працюють правильно.
- Перевірка файлу відповідей (`tools/Validate-Unattend.ps1`, 37 перевірок) і перевірка в програмі повідомляють про
  ім'я комп'ютера неправильного вигляду та про символи поза ASCII в облікових записах.
- Профілі зберігаються у форматі 4; профілі форматів 2 і 3 відкриваються без попередження, ім'я комп'ютера в них
  вибирає Windows. Версія каталогу 0.7: правила не змінилися, профіль, збережений із каталогом 0.6, відкривається зі
  звичайним попередженням про версію каталогу.

## English

The second candidate of version 1.3. Changes after 1.3.0-rc.1:

- The computer name in the "Installation" form: "Windows chooses a name" (as before, `DESKTOP-` and random
  characters), "This name" or "A name from a template". A name has up to 15 Latin letters, digits and hyphens and
  cannot be only digits. A template adds parts computed on each computer during installation: `{serial}` (the end of
  the serial number of the BIOS), `{mac}` (the end of the address of the network adapter), `{random}` (random letters
  and digits). A number sets the length, for example `OFFICE-{serial:6}`. A part that cannot be read becomes random
  characters. The name is set during installation only; the "This PC" menu never renames a running computer. Test a
  template in a virtual machine.
- Cyrillic in accounts: Windows Setup 24H2 and later turns characters outside the Latin alphabet into question marks
  (as happened to the description of a user). The Cyrillic display name and description are now set by
  `Post-OOBE.ps1` after the out-of-box experience, and the answer file holds Latin text only. An account name or a
  password in Cyrillic cannot be repaired that way, so the check reports them as errors: write them in Latin letters.
  The other places that carry Cyrillic (scripts, logs, the scripts of the "This PC" menu, the audit report) were
  checked and work correctly.
- The answer file checker (`tools/Validate-Unattend.ps1`, 37 checks) and the check in the program report a computer
  name of the wrong shape and characters outside ASCII in accounts.
- Profiles are saved in format 4; profiles of formats 2 and 3 open without a warning, and Windows chooses their
  computer name. Catalog version 0.7: the rules did not change, and a profile saved with catalog 0.6 opens with the
  usual warning about the catalog version.
