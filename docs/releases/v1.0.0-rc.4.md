# WinKickOff 1.0.0-rc.4

## Русский

Четвёртый кандидат в выпуск. Изменения после 1.0.0-rc.3:

- Основной язык программы теперь английский. Русский и украинский переводы лежат в отдельных файлах, и программа
  сама находит все доступные языки. Чтобы добавить язык, достаточно положить файл `strings.<код>.json` в папку
  `resources` и, по желанию, перевод правил `<код>.toml` в `rules\lang`. Непереведённое показывается по-английски.
- В меню «Язык» первым стоит пункт «Как в Windows», он выбран по умолчанию: программа берёт язык интерфейса
  Windows, если для него есть перевод, иначе английский. Язык, выбранный раньше, сохраняется.
- Новое меню «Тема»: «Как в Windows» (светлая или тёмная, как настроено в Windows), «Светлая», «Тёмная»,
  бежево-кофейная «Латте» и шуточная «Матрица». В цветных темах полоса меню, выпадающие меню и заголовок окна
  тоже в цветах темы (заголовок в Windows 11). Свою тему можно сделать файлом в `resources\themes` по образцу
  `dark.json`.
- В цветных темах меню открывается и с клавиатуры: Alt и подчёркнутая буква, F10 открывает первое меню.
- В портабельной версии папки `resources` и `rules` лежат внутри `_internal`.

Правила и их действия не менялись: файл ответов из этой версии выполняет то же, что и из 1.0.0-rc.3. В файл
записываются только имя и описание пресета, теперь по-английски (в программе они показываются в переводе).

## Українська

Четвертий кандидат у випуск. Зміни після 1.0.0-rc.3:

- Основна мова програми тепер англійська. Український і російський переклади лежать в окремих файлах, і програма
  сама знаходить усі доступні мови. Щоб додати мову, достатньо покласти файл `strings.<код>.json` у папку
  `resources` і, за бажанням, переклад правил `<код>.toml` у `rules\lang`. Неперекладене показується англійською.
- У меню «Мова» першим стоїть пункт «Як у Windows», його обрано за замовчуванням: програма бере мову інтерфейсу
  Windows, якщо для неї є переклад, інакше англійську. Мова, обрана раніше, зберігається.
- Нове меню «Тема»: «Як у Windows» (світла або темна, як налаштовано у Windows), «Світла», «Темна», бежево-кавова
  «Лате» і жартівлива «Матриця». У кольорових темах смуга меню, випадні меню і заголовок вікна теж у кольорах
  теми (заголовок у Windows 11). Свою тему можна зробити файлом у `resources\themes` за зразком `dark.json`.
- У кольорових темах меню відкривається і з клавіатури: Alt і підкреслена літера, F10 відкриває перше меню.
- У портабельній версії папки `resources` і `rules` лежать усередині `_internal`.

Правила та їхні дії не змінювалися: файл відповідей із цієї версії виконує те саме, що й із 1.0.0-rc.3. У файл
записуються лише назва й опис пресета, тепер англійською (у програмі вони показуються в перекладі).

## English

The fourth release candidate. Changes since 1.0.0-rc.3:

- The main language of the program is now English. The Russian and Ukrainian translations are separate files, and
  the program finds every available language by itself. To add a language, put a file `strings.<code>.json` into
  the `resources` folder and, if you like, the rule translations `<code>.toml` into `rules\lang`. Anything not
  translated is shown in English.
- The "Language" menu starts with "As in Windows", the default: the program takes the Windows display language
  when there is a translation for it, otherwise English. A language chosen earlier is kept.
- New "Theme" menu: "As in Windows" (light or dark, as set in Windows), "Light", "Dark", the beige and coffee
  "Latte" and the playful "Matrix". In the coloured themes the menu bar, the drop-down menus and the window title
  bar take the theme colours too (the title bar on Windows 11). A theme of your own is a file in
  `resources\themes` modelled on `dark.json`.
- In the coloured themes the menus open from the keyboard as well: Alt with the underlined letter, F10 opens the
  first menu.
- In the portable build the `resources` and `rules` folders are inside `_internal`.

Rules and their actions did not change: an answer file built with this version does the same as with
1.0.0-rc.3. Only the name and the description of the preset written into the file are now English (the program
shows them translated).
