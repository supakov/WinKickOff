# WinKickOff 1.1.0-rc.2

## Русский

Второй кандидат версии 1.1. Новое после 1.1.0-rc.1: политики ADMX со списками значений и многострочным текстом.

- Импорт шаблонов больше не пропускает политики со списками (например, разрешённые адреса, устройства, серверы) и
  с многострочным текстом: в шаблонах Windows 11 сборки 26300 пропущено 20 политик вместо 190.
- Список редактируется в многострочном поле, по одному элементу в строке; если у элементов свои имена, строка
  пишется как `имя=значение`. Проверка находит пустые и слишком длинные строки, недопустимые символы, строки без
  `=` и повторы имён.
- Список, который шаблон не разрешает дополнять, заменяет все значения своего ключа, как групповая политика;
  правило «(Отключено)» оставляет ключ пустым.
- «Этот ПК» проверяет, применяет и возвращает списки к значениям Windows: перед изменением сохраняется каждое
  затронутое значение, и откат через `Undo-Apply.ps1` возвращает их по одному.
- Импорт, сделанный версией 1.1.0-rc.1, загружается, но списков в нём нет; в описании его ветки указано, сколько
  политик пропущено. Удалите его и импортируйте шаблоны заново.

Встроенные правила и пресеты не менялись; каталог получил номер 0.5 из-за новых функций сценариев, поэтому при
открытии старого профиля появится обычное предупреждение о версии каталога.

## Українська

Другий кандидат версії 1.1. Нове після 1.1.0-rc.1: політики ADMX зі списками значень і багаторядковим текстом.

- Імпорт шаблонів більше не пропускає політики зі списками (наприклад, дозволені адреси, пристрої, сервери) і з
  багаторядковим текстом: у шаблонах Windows 11 збірки 26300 пропущено 20 політик замість 190.
- Список редагується в багаторядковому полі, по одному елементу в рядку; якщо елементи мають власні імена, рядок
  пишеться як `ім'я=значення`. Перевірка знаходить порожні й задовгі рядки, неприпустимі символи, рядки без `=`
  і повтори імен.
- Список, який шаблон не дозволяє доповнювати, замінює всі значення свого ключа, як групова політика; правило
  «(Вимкнено)» залишає ключ порожнім.
- «Цей ПК» перевіряє, застосовує та повертає списки до значень Windows: перед зміною зберігається кожне зачеплене
  значення, і відкат через `Undo-Apply.ps1` повертає їх по одному.
- Імпорт, зроблений версією 1.1.0-rc.1, завантажується, але списків у ньому немає; в описі його гілки вказано,
  скільки політик пропущено. Видаліть його та імпортуйте шаблони знову.

Вбудовані правила й пресети не змінювалися; каталог отримав номер 0.5 через нові функції сценаріїв, тому під час
відкриття старого профілю з'явиться звичайне попередження про версію каталогу.

## English

The second candidate of version 1.1. New since 1.1.0-rc.1: ADMX policies with lists of values and multi-line
text.

- The import of templates no longer skips policies with lists (for example allowed addresses, devices, servers)
  and multi-line text: of the templates of Windows 11 build 26300, 20 policies are skipped instead of 190.
- A list is edited in a multi-line box, one item per line; when the items have names of their own, a line is
  written as `name=value`. The check finds empty and too long lines, characters that are not allowed, lines
  without `=` and repeated names.
- A list that the template does not allow to add to replaces every value of its key, as Group Policy does; the
  "(Disabled)" rule leaves the key empty.
- "This PC" checks lists, applies them and returns them to the Windows values: every value touched is saved
  before the change, and the rollback with `Undo-Apply.ps1` brings them back one by one.
- An import made by 1.1.0-rc.1 loads, but has no lists; the description of its branch says how many policies were
  skipped. Delete it and import the templates again.

Built-in rules and presets did not change; the catalog is now 0.5 because of the new script functions, so an
older profile opens with the usual warning about the catalog version.
