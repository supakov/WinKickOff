# WinKickOff 1.4.0-rc.5

## Русский

Пятый кандидат версии 1.4. Изменения после 1.4.0-rc.4:

- Токен доступа MCP, который создаёт окно, больше не начинается с дефиса. Прежде примерно один токен из 64 начинался
  с `-`, и команда `--mcp http --token ТОКЕН` не принимала его. Токен такого вида, созданный версией по 1.4.0-rc.4
  включительно, пишется слитно: `--token=ТОКЕН`; можно и создать новый токен в меню MCP.
- Закрытие окна во время длительной операции больше не печатает в консоль ошибки Tcl («application has been
  destroyed»): индикатор окна операции останавливается до того, как окно закрывается.

## Українська

П'ятий кандидат версії 1.4. Зміни після 1.4.0-rc.4:

- Токен доступу MCP, який створює вікно, більше не починається з дефіса. Раніше приблизно один токен із 64 починався
  з `-`, і команда `--mcp http --token ТОКЕН` його не приймала. Токен такого вигляду, створений версією до
  1.4.0-rc.4 включно, пишеться разом: `--token=ТОКЕН`; можна й створити новий токен у меню MCP.
- Закриття вікна під час тривалої операції більше не друкує в консоль помилки Tcl («application has been
  destroyed»): індикатор вікна операції зупиняється до того, як вікно закривається.

## English

The fifth candidate of version 1.4. Changes after 1.4.0-rc.4:

- The MCP access token the window makes no longer starts with a hyphen. Before, about one token in 64 started with
  `-`, and the command `--mcp http --token TOKEN` did not accept it. A token of that kind made by a version up to
  1.4.0-rc.4 is written as one word: `--token=TOKEN`; a new token can also be made in the MCP menu.
- Closing the window during a long operation no longer prints Tcl errors to the console ("application has been
  destroyed"): the progress bar of the operation window stops before the window closes.
