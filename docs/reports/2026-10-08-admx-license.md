# Лицензия шаблонов ADMX Windows и каталоги программы

Дата: 08.10.2026. Открытый пункт задачи T23: каталоги программы ждут проверки лицензии шаблонов Microsoft (решение
заказчика от 04.10.2026 «Отложить до проверки»).

Это не юридическое заключение, а сводка того, что написано в лицензии. Окончательное решение за заказчиком; при
сомнении стоит спросить юриста.

## Вопрос

Можно ли включить в сборку WinKickOff готовые каталоги (`WinKickOff/catalogs/*.json`, в сборке `*.json.xz`),
сделанные из шаблонов ADMX и ADML Windows (`C:\Windows\PolicyDefinitions`)? Каталог содержит записи политик:
разделы и значения реестра, варианты, а также названия и пояснения политик на английском, русском и украинском
языках почти в том виде, в каком их написала Microsoft.

## Что сказано в лицензии Windows

Источник: текст лицензии Windows 11 Pro, установленной на этом компьютере,
`C:\Windows\System32\en-US\Licenses\_Default\Professional\license.rtf` (Microsoft Software License Terms, Windows
Operating System, редакция «Last updated April 2024»). Русский и украинский тексты лежат рядом, в папках `ru-RU` и
`uk-UA`. Файл только прочитан.

- Раздел 1.a (Applicability): договор распространяется на программное обеспечение Windows, предустановленное или
  установленное пользователем, на включённые в него шрифты, значки, изображения и звуки, а также на обновления. Файлы
  `PolicyDefinitions` поставляются вместе с Windows и её обновлениями, то есть входят в это ПО.
- Раздел 2.a (License): лицензия даёт право установить и запускать один экземпляр Windows на одном устройстве.
- Раздел 2.c (Restrictions): права, которые договор прямо не предоставляет, остаются за производителем устройства и
  Microsoft. Среди запретов прямо названо: «publish, copy (other than the permitted backup copy), rent, lease, or lend
  the software», то есть публиковать и копировать ПО, кроме разрешённой резервной копии.

Что из этого следует: лицензия Windows не даёт права переносить её файлы в другой продукт и распространять их.
Каталог программы повторяет структуру ADMX и тексты ADML, то есть содержит копию части ПО Windows. Поставлять такой
каталог вместе с WinKickOff эта лицензия не разрешает.

## Отдельный пакет шаблонов Microsoft

Microsoft выпускает шаблоны и отдельно, установщиком «Administrative Templates (.admx) for Windows 11» в Центре
загрузки (файл MSI около 13 МБ). Его лицензия показывается только при установке; в открытом доступе её текста найти
не удалось. Похожий пакет MDOP Administrative Templates разрешает устанавливать и использовать любое число копий на
своих устройствах, о распространении в нём ничего не сказано, а все права, не предоставленные прямо, Microsoft
оставляет за собой. Если заказчику важна поставка каталогов, лицензию пакета для Windows 11 можно прочитать, скачав
MSI с сайта Microsoft: в виртуальной машине или по отдельному разрешению заказчика на этом компьютере.

## Что это решение не затрагивает

- Импорт шаблонов этой Windows и импорт папки с шаблонами: человек читает файлы своей лицензионной Windows на своём
  устройстве, программа их никуда не передаёт. Всё работает как сейчас и даёт то же дерево политик, что и каталог
  программы.
- Экспорт в файл каталога: кому передать файл, решает сам человек. Передача файла с шаблонами Microsoft другим лицам
  может противоречить разделу 2.c, поэтому об этом стоит предупредить в пользовательской документации.
- Правила WinKickOff (`WinKickOff/rules/`): их тексты написаны нами, ссылки на документацию Microsoft приводятся,
  тексты шаблонов не копируются.

## Шаблоны других производителей

Если каталоги программы когда-нибудь будут включать шаблоны Edge, Office, Chrome или Brave, лицензию каждого нужно
проверить отдельно: шаблоны Edge и Office Microsoft распространяет на своих условиях, шаблоны Chrome и Brave
поставляются в их корпоративных пакетах. Этот отчёт их не оценивает.

## Рекомендация

1. Не включать в сборку каталоги, сделанные из шаблонов Microsoft. Пункт меню «Импортировать каталог программы»
   оставить недоступным, как сейчас: механизм готов и пригодится для шаблонов с лицензией, которая разрешает
   распространение.
2. Предлагать пользователям импорт шаблонов своей Windows: результат тот же, без распространения файлов Microsoft.
3. Добавить в пользовательскую документацию о шаблонах ADMX предупреждение о передаче файлов каталога с шаблонами
   Microsoft другим лицам.
4. Если поставка каталогов всё же нужна: прочитать лицензию отдельного пакета MSI и при необходимости получить
   письменное разрешение Microsoft или заключение юриста.
