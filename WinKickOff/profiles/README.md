# Profiles

`*.json` files in this folder are presets and user profiles.

- `preset-office.json`: the Office preset. It equals the catalog defaults: the hand-written answer
  file v0.2 (Appendix B) with the later changes listed in `V02_DIFFERENCES` of `tests/v02_actions.py`.
- `preset-strict.json`: the Strict preset: Office plus restrictions that may disturb old programs
  (Controlled Folder Access in block mode, SmartScreen Block, the ASR prevalence rule in block mode, unsigned
  programs from USB blocked, UAC always asks the administrator, Microsoft Update for other products, NetBIOS off,
  VBScript removed).
- `preset-laptop.json`: the Laptop preset: Office with the screen locked after 10 minutes. Automatic
  device encryption is prevented here too, as in every preset (BitLocker comes with key escrow, a separate task).
- `preset-home.json`: the Home preset, a lighter setup for home PCs, defined by the list `HOME_RULES` in
  `tools/make_presets.py` (70 rules). It keeps the setup screens of Office (hardware checks bypassed, no
  Microsoft account or network screens, BitLocker prevented), removes extra apps, OneDrive and Quick Assist, turns
  off ads, widgets, web search, Copilot and Recall, sets minimal telemetry (level 0) and Delivery Optimization
  without the cloud (99), shows file extensions, opens File Explorer to This PC and asks for the product key. It
  leaves out the WinKickOff protection set: apart from Defender notifications and Delivery Optimization, the UAC,
  LSA, Defender, ASR, SmartScreen, network, logging, update, browser and post-installation rules write nothing, so
  Windows keeps its defaults (answer file copies stay in `C:\Windows\Panther`). .NET Framework 3.5, the automatic
  Print Spooler start, the user region, the input language list, the display language pin, AutoRun off and the AI
  rules of Notepad, Paint, Office and Edge are off too; the check shows 13 baseline warnings. Not for work PCs; "Home" is not the Windows Home edition.

All presets are generated by `python tools/make_presets.py` (deterministic, fixed timestamps). The editor
never overwrites a preset: a changed preset is saved under a new name.

Profiles may contain account passwords in plain text, so user profiles are not versioned (`.gitignore`);
presets are versioned and contain no passwords.
