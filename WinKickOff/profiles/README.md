# Профили

Файлы `*.json` в этой папке: профили пользователя и пресеты.

- `preset-office.json`: пресет «Офис», равен каталогу по умолчанию (файл ответов v0.2). Создаётся
  задачей T04 командой сохранения профиля из каталога; пока отсутствует, приложение строит его из каталога при запуске.
- `preset-strict.json`: строгий профиль (задача T04).

Профили могут содержать пароли учётных записей открытым текстом: пользовательские профили не
версионируются (`.gitignore`), пресеты `preset-*.json` версионируются и паролей не содержат.
