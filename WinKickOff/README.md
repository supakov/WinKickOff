# WinKickOff

Редактор конфигурации установки Windows 11 Pro для рабочих групп без домена. Показывает все правила
настройки одним деревом с флажками и поиском, выключает зависимые правила автоматически, хранит выбор
в профиле JSON и собирает `autounattend.xml` только из выбранного.

Состояние: каркас (25.09.2026). Каталог правил перенесён из файла ответов v0.2 целиком; загрузчик,
резолвер зависимостей, профиль и окно с деревом работают; генератор, валидатор и импорт в работе
(см. `../draft/install-editor/todo/`).

Постановка, архитектура, модель данных, план: `../draft/install-editor/`.

## Требования

- Python 3.14 (только стандартная библиотека: tkinter, tomllib, json, xml.etree, logging).
- Windows 10 1809+ или Windows 11.

## Запуск из исходников

```powershell
cd WinKickOff
python -m winkickoff
```

## Тесты

```powershell
cd WinKickOff
python -m unittest discover -s tests -v
```

Тесты читают файлы проекта и пишут только во временные папки. Тест покрытия
(`tests/test_coverage_v02.py`) сравнивает каталог правил с файлом `../autounattend.xml` v0.2:
каждое действие файла должно присутствовать в каталоге при значениях по умолчанию.

## Структура

```
WinKickOff/
  winkickoff/        код: core (логика без интерфейса), ui (tkinter)
  rules/             каталог правил (TOML): groups.toml, NN-<направление>.toml, lang/
  templates/         рантайм XML и PowerShell (T05)
  resources/         справочники раскладок и часовых поясов, строки интерфейса
  profiles/          пресеты (создаются из каталога, см. profiles/README.md)
  tests/             unittest
  tools/             run-tests.ps1, build.ps1 (T12)
```

Рабочие папки `output/`, `logs/` создаются рядом при первом запуске и не версионируются.

## Правила проекта

- Никаких зависимостей за пределами стандартной библиотеки в приложении.
- Никаких записей вне папки приложения; никаких обращений в интернет.
- Без длинных и коротких тире в коде, данных и строках.
- Правки каталога проверяются `python -m unittest` до коммита.
