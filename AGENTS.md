# AGENTS.md: карта проекта «Windows installer»

Файл для агентов и разработчиков: где что лежит, что читать первым, какие правила действуют,
в каком состоянии работы. Обновляется при каждом изменении структуры, команд или статуса задач.
Последнее обновление: 25.09.2026 (ночь: генератор, пресеты, профили и сборка в окне WinKickOff; задача T15).

Репозиторий: https://github.com/supakov/WindowsInstaller (приватный, ветка `main`). Локальная папка
`C:\Users\User\projects\Windows installer` и репозиторий должны совпадать: после каждой законченной
задачи коммит и push. Сообщения коммитов на русском, первая строка до 72 символов, без длинных тире,
в конце строка `Co-Authored-By: <модель агента> <noreply@anthropic.com>` для коммитов, сделанных агентом
(имя модели берётся из текущей сессии агента, например `Claude Opus 5.5`).

## 1. О проекте в трёх предложениях

Файл ответов `autounattend.xml` для автоматической установки Windows 11 Pro в малых рабочих группах
без домена, где за ПК сидят непрофессионалы, а организация находится под постоянными кибератаками.
Приоритет: безопасность и обновляемость, без косметики и сторонних утилит. Следующий шаг: настольный
редактор WinKickOff (Python 3.14, tkinter, портабельный), который показывает все правила деревом с
поиском, выключает зависимые правила автоматически и собирает файл ответов только из выбранного.

## 4. Правила проекта (обязательны для любого агента)

1. Рабочий ПК заказчика неприкосновенен. На нём разрешено только чтение (реестр, службы, файлы,
   логи) и запуск тестов, которые пишут только во временные папки или внутрь папки проекта.
   Никаких «временных» или «обратимых» изменений системы: 12.09.2026 такой тест сломал раскладки
   клавиатуры. Всё, что меняет систему, выполняется в виртуальной машине или описывается как инструкция.
   Исключение только по отдельной явной команде заказчика на конкретное действие.
2. Длинное тире (U+2014) и короткое тире (U+2013) запрещены во всех создаваемых текстах: документы,
   код, данные, комментарии, строки интерфейса, сообщения коммитов. Диапазоны чисел через дефис
   (08:00-20:00, T01-T06). Проверка: `WinKickOff/tests/test_sources.py` для редактора и команда в разделе 5 для всего дерева.
3. Отчёты по запросу заказчика выдаются в Markdown в `docs/`; Word только по явной просьбе «в Ворд».
4. Язык документов и общения: русский. Идентификаторы, имена параметров, ключи реестра и код на английском.
5. Стартовые учётные записи Admin и User без паролей это осознанное решение заказчика: пароли и группы
   назначает отдельный проект после установки. Не предлагать это «исправить».
6. Язык интерфейса Windows не меняется: `UILanguage` равен языку ISO (сейчас uk-UA).
7. Любая правка `autounattend.xml`: сначала `docs/reference/00-architecture.md` раздел 3
   (Path до 259 символов, без комментариев в компонентах, exit 0), после правки валидатор, версия в
   шапке файла и в README, карточка параметра в справочнике, соответствующее правило в `WinKickOff/rules/`
   (тест покрытия `test_coverage_v02.py` упадёт, если каталог и файл разойдутся).
8. Редактор: только стандартная библиотека Python в приложении; тесты на `unittest`; каталог правил
   в TOML, профили в JSON; правила без кода. Правка шаблонов рантайма (когда появятся) требует новой
   `templates/VERSION`.
9. Инструменты записи файлов у агента превращают escape-последовательности вида `\uXXXX` в реальные
   символы. Символы, которые не должны попадать в файл (например тире в регулярных выражениях),
   строятся в коде через `chr(0x2013)`, а не через escape.

## 5. Команды

Проверить файл ответов (только чтение, PowerShell 5.1):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Validate-Unattend.ps1
```

Тесты редактора (Python 3.14, стандартная библиотека, ничего не меняют на машине):

```powershell
cd WinKickOff
python -m unittest discover -s tests -v
```

Пересоздать пресеты после правки каталога (тест `test_presets.py` падает, если забыть):

```powershell
cd WinKickOff
python tools/make_presets.py
```

Запустить редактор из исходников:

```powershell
cd WinKickOff
python -m winkickoff
```

Проверить дерево на длинные и короткие тире (PowerShell; grep в Git Bash не понимает классы Юникода):

```powershell
Get-ChildItem -Recurse -Include *.md,*.ps1,*.py,*.toml,*.json -File | Where-Object { $_.FullName -notmatch '\\(original|\.git|__pycache__)\\' } | ForEach-Object { $n = ([regex]::Matches([IO.File]::ReadAllText($_.FullName, [Text.Encoding]::UTF8), '[\u2013\u2014]')).Count; if ($n) { "$($_.FullName): $n" } }
```

Пустой вывод означает, что тире нет. Проверка после установки в ВМ: чек-лист в `README.md`.

## 6. Ключевые факты, которые легко потерять

- Первая установка v0.1 (13.09.2026) упала в specialize с 0x80220005: две команды длиннее 259 символов.
  Предел документирован Microsoft. Исправлено в v0.2.
- Целевой ISO: украинский Windows 11 Pro (setupact.log: Language uk-ua, Region UA), сборка 26200 (25H2).
- «Русский (Украина)» (`ru-UA`) не имеет LCID; в XML пишется обычный русский `0419:00000419`,
  а `Setup-User.ps1` заменяет его при первом входе (Windows назначает временный код `2000:00000419`).
- Windows 11 24H2 оставляет копии файла ответов в `C:\Windows\Panther`; `Post-OOBE.ps1` их удаляет.
- `auditpol` на украинском образе не принимает английские имена подкатегорий; используются GUID.
- Задача планировщика создаётся из XML, чтобы работать от батареи; `Register-ScheduledTask` в specialize ненадёжен.
- Все три встроенных скрипта завершаются `exit 0`; обёртки команд перехватывают ошибки в `C:\Windows\Temp\ua.err`.
- Известные несоответствия v0.2 перечислены в `docs/reference/17-cross-links.md`, раздел 3; в каталоге
  редактора `MapsBroker` уже привязан к удалению Карт, а не к Xbox.
- Из 153 действий скрипта v0.2 47 выполнялись безусловно; в редакторе каждое действие принадлежит
  правилу (130 правил: 47 базовых, 18 ASR, 33 приложения и т. д.), любое можно выключить.
- GitHub отклоняет push с личным адресом почты в авторе коммита; в этом репозитории локально задан
  служебный адрес `265459095+stanislavperec-ua@users.noreply.github.com` (`git config user.email`,
  только для этой папки). Файлы хранятся байт в байт (`.gitattributes`: `* -text`), CRLF.
- На рабочем ПК есть Python 3.14.3 с tkinter 8.6 и tomllib; pytest отсутствует и не устанавливается.
  PyInstaller тоже не установлен: установка пакета это изменение ПК, поэтому сборка exe (T12) только в ВМ
  или по отдельной команде заказчика.
- Сборка WinKickOff повторяет v0.2 по смыслу, а не байт в байт: тест `test_build.py` сравнивает действия
  `Setup-System.ps1`, команды проходов, International-Core, OOBE, учётные записи и часовой пояс.
  `tools/Validate-Unattend.ps1` принимает оба варианта (блок `$Config` в v0.2 или маркеры `# [rule.id]`).
- Всё, что пишет генератор (шапка, маркеры, встроенный профиль), только ASCII; профиль встраивается в
  `Extensions/Profile` как JSON с экранированными национальными символами, поэтому «Открыть профиль из
  собранного XML» восстанавливает настройки из готового файла.
- Treeview в tkinter не раскладывает строки в скрытом окне; дымовой тест окна показывает его прозрачным
  за пределами экрана. Флажки в дереве это картинки (`identify_element` возвращает `image`), «+» это
  `Treeitem.indicator`: щелчок по «+» только раскрывает ветку.
- Каталог 0.3: страна перенесена в параметры правила `default-user.region` (строка `"241"`), поле
  `iso_language` удалено; старые профили переносятся при загрузке с предупреждением.

## 8. Как обновлять этот файл

- Изменилась структура каталогов: раздел 3.
- Появилась команда запуска или проверки: раздел 5.
- Выполнена или начата задача: раздел 7 и `draft/install-editor/todo/README.md`.
- Выяснен факт, который влияет на будущие правки: раздел 6.
- Дата в шапке при каждом изменении.
